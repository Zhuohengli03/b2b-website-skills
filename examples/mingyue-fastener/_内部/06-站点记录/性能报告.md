# 性能报告 · 铭岳紧固件（示例）

> 产出方：前端。读者：SEO、测试。
> 工具：Playwright 1.x + Chromium 1194（headless），`PerformanceObserver` 采 LCP / FCP / CLS，CDP `Network.emulateNetworkConditions` + `Emulation.setCPUThrottlingRate` 节流；每组取 3 次中位数。本地静态服务（`node build.mjs --serve`），TTFB ≈ 2–6 ms，**不含真实 CDN / TLS 开销**；上线后请 SEO 用 PageSpeed Insights 复测（无外网，本环境跑不了 Lighthouse 远程评分）。
> 字体为 system-ui 兜底（正式字体未到），自托管 woff2 后 LCP 预计 +50–150 ms（swap，不阻塞）。

## 一、核心指标（硬约束：LCP ≤ 2.5 s、CLS < 0.1、INP < 200 ms）

| 条件 | 页面 | FCP | **LCP** | **CLS** | load | 结论 |
|---|---|---|---|---|---|---|
| 桌面 1440 · 无节流 | 首页 `/` | 116 ms | **116 ms** | **0** | 92 ms | 通过 |

| | 型号页 | 88 ms | 88 ms | 0 | 45 ms | 通过 |
| | Contact | 84 ms | 84 ms | 0 | 52 ms | 通过 |

| | Products / 型号页 / Contact | 224 / 220 / 208 ms | 224 / 220 / 208 ms | 0 | ≤ 188 ms | 通过 |

- LCP 元素：首页为 H1 文字（桌面）/ H1（手机）；内页为 H1。全站无首屏图片、无 preloader、无字体阻塞，LCP = FCP。
- CLS：全部 0（首屏静态；表格 / 占位框尺寸固定；Counter 滚数不改布局；渐入只动 transform / opacity）。目录页带筛选参数直达（`/products/?class=10.9`）首次测得 0.03（JS 过滤隐藏行），仍 < 0.1；无参数时 0。
- INP：无长任务（site.js 12.9 KB，全部事件处理 < 5 ms；滚动驱动用 rAF 合并）；本环境无法模拟真实交互延迟，估计 < 50 ms，上线后以 CrUX 为准。
- 18 个页面 × 3 档视口（390 / 768 / 1440）：`scrollWidth === innerWidth`（无横向溢出）、每页 1 个 H1、console 0 错误 0 警告。

## 三、测试条件

- 设备：Linux x86_64 容器，Chromium 1194 headless；桌面 1440×900 DPR 1；手机 390×844 DPR 3 `isMobile` + touch；平板 768×1024。
- 网络：无节流 / 4G（10 Mbps↓ 5 Mbps↑ 40 ms）/ Slow 4G（1.6 Mbps↓ 750 kbps↑ 150 ms）；CPU 节流 ×4（手机）。
- 脚本：`scratchpad/check.mjs`（全页扫描）、`scratchpad/perf.mjs`（节流中位数）、`scratchpad/func.mjs`（交互行为），运行记录见本文件数据；未随项目交付。

## 四、上线前给 SEO / 后端的性能项

1. CDN 开 gzip / brotli 与缓存头：`/assets/*` 一年 + 文件名加 hash（当前无 hash，改版时需 purge），HTML `no-cache`。
2. 字体自托管后在 `<head>` 预加载首屏两个字重（Manrope 700、400），见 `site.css` 顶部注释。
3. 图片到位后：webp、`width/height` 属性、首屏外 `loading="lazy"`、载体图例外 ≤ 300KB。
4. GA4 / 同意条脚本一律 `defer` 或延迟到交互后加载，避免把 INP 拖过 200 ms。
