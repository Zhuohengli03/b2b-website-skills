## 一、素材结论（先说硬约束）

素材清单第五节：车间 / 产线 0 张、5 类产品图 0 张、证书 0 份、logo 源文件未收、视频未收、旧站不可抓取（全部 L4）。用户批准零素材继续（RUN.md）。

**结论：素材不支撑摄影驱动。** 按 SKILL 第五步第 7 条，主风格只能在国际企业风 / 工业硬核风 / Bento 排版型中选；极简北欧、摄影驱动、暗色高级科技三者禁用。证据位（车间、产品、证书）一律占位标 `[待确认]`，图到位后换图不重排。

## 二、四项输入各指向哪个流派

| 输入 | 事实（出处） | 指向 |
|---|---|---|
| 公司类型 | 生产型工厂，自有厂房、冷镦、热处理（第 1 项） | 国际企业风（标准件工厂，选型人是采购部门） |
| 产品性质 | DIN / ISO 标准件为主 + 汽车 10.9 级 + 非标冷镦（第 2 项）；采购按标准号与参数选（研究简报二节共性 2） | 国际企业风为主；参数区、型号、数字可借工业硬核的点缀 |
| 目标市场审美 | 德国 > 美国 > 波兰（第 4 项）；德国本土站白底、克制、一主色、数字型信任、首屏静态（研究简报四节） | 国际企业风；饱和度降一档、留白加一档 |
| 素材条件 | 零实拍（素材清单） | 三选一；国际企业风靠网格与留白撑得住，工业硬核的深底无图会空，Bento 只作一处版式 |

**主风格：国际企业 / 瑞士网格风。点缀：工业硬核（只用在参数表、型号、Counter、线稿这四类元素）。** 第二候选工业硬核风不选的原因：你的原话「bossard 干净」「不要花里胡哨」（第 10 项），德国基线是白底，零实拍下深底会显空。两种以上风格混用是最常见的错误，Bento 只用于首页能力总览一块，不算第三种风格。

## 四、字体方案

风格定字族 → 背景定字重 → 页面定层级 → 产品定点缀。

| 项 | 方案 |
|---|---|
| 标题字族 | **Manrope** 600（H2–H3）/ 700（H1、hero）；大字号字距 −0.02em |
| 正文字族 | **Manrope** 400，16–18px，行高 1.6，色 `#1B1D21`；14px 说明文字用 500 |
| 点缀字族 | **IBM Plex Mono** 500 / 600：型号串（`DIN912-M6x20-12.9-BO`）、参数表数值列、Counter 数字、证书编号、流程步骤序号。**只出现在这五类元素**，不进标题与正文 |
| 字号阶梯 | 14 / 16 / 18 / 24 / 32 / 48 / 64；hero 桌面 56、手机 36；Counter 64（手机 40）；参数表 15 |
| 数字 | 全站 `font-variant-numeric: tabular-nums`；参数表数值与单位分列对齐 |
| 深色底（页尾 CTA） | 正文 400 → 500，17px，行高 1.7，字距 +0.01em，字色 `#F5F5F5`；不用 300 以下 |
| 品牌色底 | 只放白字；标题 700；正文 ≤ 2 行 |
| 字重文件 | Manrope 400 / 500 / 600 / 700 + Plex Mono 500 / 600，自托管 woff2，`font-display: swap`，总量 ≤ 300KB；回退栈 Manrope → Arial, Helvetica；Plex Mono → Consolas, Menlo, monospace |
| 多语言覆盖 | 首期英文；德语 ä ö ü ß 与波兰语 ą ć ę ł ń ó ś ź ż 会出现在买家名与 FAQ 里 → 子集化时**必须保留 Latin Extended**，自托管前逐字核对 |
| 大写字距 | 全大写 + 字距 0.08em 只用于 Counter 标签与页脚小标题，一页一处手法 |

为什么不是 Inter 配 Inter：Inter 是 AI 默认模板的字体，与同行站无区分；Manrope 同属几何无衬线但字形更圆整，配 Plex Mono 的工程感能把「懂参数」的信号落在型号上，而不是整站变成工业硬核。

## 五、个性化抓手（四条，每条：来源 → 事实 → 落到的决定）

1. **产品几何与工艺** → 内六角圆柱头 DIN 912 / ISO 4762 是主打第一品类，法兰面 DIN 6921 第二；表面处理发黑与达克罗；型号命名 `标准号-规格-等级-表面`（第 2 项，F6、F7）；标准件图纸由设计按 DIN / ISO 尺寸表自绘线稿（D12 默认）→ **决定**：① 全站母题 = 内六角截面（外圆 + 内六边形）的单线 SVG，用作分类图标、分类页 hero 线稿、404 与加载占位；② 分隔线用螺纹节距节奏（等距短竖线），不用通栏实线；③ 色板中性色直接取发黑 `#1B1D21` 与达克罗 `#A9AFB7`（见第三节）；④ 型号串用 Plex Mono 并按四段对齐（`DIN912 · M6x20 · 12.9 · BO`），目录页每行型号左对齐成一列可扫读的「标准号列」。
2. **公司历史与数字** → 2009 年成立；自有热处理线（网带炉）；3 台全自动光学筛选机、汽车件 100% 全检；IATF 16949（2023）；非标 15 天出样；年产 1.8 亿件（F2、F3、F4、F5、F9）；研究简报三节与九节 3：14 台冷镦机在国内头部 400+ 台面前不是差异点 → **决定**：① 首屏定位句讲「made in-house, heat-treated in-house, 100% optically sorted」，不讲「since 2009」也不讲台数；② 首页 Counter 四个数固定为 **100% optically sorted（automotive）/ 15-day custom samples / 180 million pcs per year / IATF 16949 `[待确认]`**，台数、23 国、40 柜不进 Counter；③ About 叙事顺序 = 工艺链（冷镦 → 搓丝 → 热处理 → 光学筛选）先、设备表次、时间轴（2009 → 2022 新四模四冲 → 2023 IATF → 2024 ISO 换证）最后；④ 强调色只给「100%」和「In-house」两个词。
3. **目标市场审美** → 德国第一、美国第二、波兰第三（第 4 项）；德国本土站首屏一句话 + 一键、首页无电话、信任靠数字与栏目、无 WhatsApp（研究简报四节、二节共性 1 与 3）；美国 CTA 直接但品类错位（九节 4）→ **决定**：① 首屏**参数先行**：左侧定位句 + 双按钮，右侧不是场景图而是一张「代表型号参数卡」（DIN 912 M6×20 12.9 BO 的线稿 + 六行参数），采购 5 秒内看到的是标准号与等级；② 主按钮全站 **Request a Quote**（中性、德国可接受），不用 Buy / Order / Call Now；③ 首页 5 个内容区块 + 2 个 CTA 大区，白底、留白加一档、饱和度降一档、首屏静态；④ 联系方式只表单 + sales@ + 固定电话 `[待确认]`，WhatsApp 按 D9 隐藏；美国只在型号页加 inch 对照行，不做美国专页。
4. **你提名的参考站** → 「bossard.com 干净、找东西方便」「德国站参数表清楚、每个型号点进去有图纸」（第 10 项）；Bossard BN 5264 页 = 属性表 + 线描缩略图 + 数据表 PDF + 替代品（研究简报二节 C1；六节截图清单 1、4）→ **决定**：① 导航 Products 下拉用**多列文字分组、按标准号排**（ISO 4762 / DIN 912、DIN 6921、Self-tapping、Automotive 10.9），不放缩略图（80px 下紧固件互相分不开）；② 目录页左侧固定筛选栏（Standard / Thread / Length / Property class / Surface / Application），右侧列表每行 = 型号串 + 四个关键参数，像一张表不像卡片墙；③ 型号页固定版式 = 左线稿图（d、k、dk、s 标注）+ 右属性表（Standard 写「ISO 4762 / DIN 912」并列）+ 下方 Downloads 三栏（Datasheet / Drawing / Certificates）+ Alternatives 一行（同规格换表面处理）；④ 导航栏常驻型号串搜索框，输入 `DIN912-M6x20` 直达型号页。

自查「换成别家公司这个设计还成不成立」：内六角母题、发黑 / 达克罗色板、「100% sorted」首屏与 Counter、按标准号排的导航与型号页版式——换成一家做自攻钉或锚栓的厂，四条都要重写，不成立。

## 六、图片处理原则（零素材期与升级后）

- 证据位（车间、产品、证书）零素材期用**同一套单线 SVG 线稿**占位并标 `[待确认]`，线稿描边 `#A9AFB7`、1.5px；不用图库图、不用渲染图冒充实拍。
- 图到位后：产品图纯色底去背、4:3；车间图加 30–50% 深色遮罩后才可叠字；证书为扫描件 PDF + 首页 JPG 缩略，不做徽章墙。
- 产品载体场景段：降级为零素材原语（`clip-path` 揭示 + `opacity` 逐项点亮），放首页 H3 工艺链段；载体默认 DIN 912 M6×20 线稿（D2），拿到俯视原图后换图不动版面。

## 七、参考类型（描述，不贴竞品链接冒充案例）

- 德国工厂官网式首页：一行大标题、一句话、一个按钮、大量留白、一张静态图位。
