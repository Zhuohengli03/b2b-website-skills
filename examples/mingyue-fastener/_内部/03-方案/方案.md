# 铭岳紧固件建站诊断与方案建议

> 产出方：策划。读者：文案、设计、后端、测试。细节在同目录三份文件；本篇只给结论。出处：需求单（题号）、研究简报（节号）、待用户决定（D 号）。

## 一、公司定性

浙江温岭一家冷镦紧固件生产型工厂（2009 年，68 人，自有热处理线与 3 台光学筛选机），主打 DIN / ISO 标准件、汽车 10.9 级螺栓和按图非标件；卖给德国、波兰的经销商和汽车二级供应商采购，美国其次；单笔 3–8 万美元、决策 2–6 个月、要样品和验厂报告（中客单批量采购）；素材实物为零，用户批准继续。依据：需求单第 1–4 项、素材清单。

## 二、旧站体检

旧站为示例域名，RUN.md 规定不可访问、不抓取，**不做体检**，品牌资产无法从旧站取回（logo、色号转 D3）。按你的自述（2016 年国内建站公司做，有滚动公告、领导视察照）判 **推倒**：结构、视觉、叙事按德美波采购重来，旧站只作事实来源；要留的简介原文按 D6 由文案重写。

## 三、站型建议

**B2B 询盘站。** 不是品牌站：无自有品牌与渠道；不是解决方案型：标准件按标准号找，不按行业组织（研究简报二节差异 3）；非标定制利润最高但转化目标同为询盘，作为一级页不另开主线。

一级导航：Products（下拉按标准号分四类 + Custom 入口 + 搜索）/ Custom Cold-Formed Parts / Quality & Downloads / About Us（含 News）/ FAQ / Contact；导航右侧型号搜索框 + Request a Quote 按钮。

首屏：定位句「冷镦紧固件，DIN / ISO 与按图，自有热处理，汽车件 100% 光学全检」（文案定稿）；主按钮 Request a Quote、次按钮 Browse Products；信任要素不是证书墙，而是右侧一张代表型号参数卡（DIN 912 M6×20 12.9 BO）。

## 四、展示技术清单

| 技术 | 页面 | 解决什么 | 素材 | 成本 |

| 可筛选目录（6 维）| Products、分类页 | 上千规格 30 秒找到型号 | 代表型号数据（D18）| 中 |
| 参数表 Tabs | 型号页 | 参数 / 下载 / 替代品分层 | 线稿 | 低 |
| 粘性询盘条 | 全站 | 手机底部常驻入口 | 无 | 低 |
| 文字型 Mega menu | 导航 | 按标准号分组找东西 | 无 | 低 |
| Counter + Bento | 首页、About | 四个有出处的数字一屏讲完 | F4、F5、F9 | 低 |
| 滚动渐入、轻悬停 | 首页、Custom | 视线按序带过证据 | 无 | 低 |
| 载体场景段（降级） | 首页工艺链段 | 线稿逐步点亮，图到位后换图 | 升级需 1 张俯视图 | 低 |

**刻意不用**：视频首屏、遮罩穿透、图片序列、360 / 3D（零素材，写入二期）；钉点、视差、横向滚动、动态文字、页面过渡、光标（你「不要会动的」，德国站首屏静态）；Logo 跑马灯、交互式地图、徽章墙、轮播、浮窗客服（无授权 / 不是差异点 / 国内站模式）。

**CTA 与区块节律检查：通过。** 首页 CTA 在首屏、证据后（工艺链 + 质量区之后）、页尾三处，中段与页尾隔一块不相邻、文案不同；按钮全站统一 Request a Quote。无需删并区块。

组件与特效清单见 `技术清单.md` 第三节：GeneratePress + GenerateBlocks + Kadence Blocks，AOS、CountUp.js，Lucide，Complianz；全部免费可商用。

## 五、风格方向

**主风格：国际企业 / 瑞士网格风；点缀：工业硬核**（只在参数表、型号、Counter、线稿）。素材不支撑摄影驱动，零素材下三选一取国际企业风：你要「干净」、德国基线是白底（研究简报四节）。

配色：主色 logo 深蓝 `#143A6E`（暂定，`[待确认：logo 吸色]`）；中性色取自表面处理——发黑 `#1B1D21`、达克罗银灰 `#A9AFB7`；强调色取自自有热处理的回火稻黄 `#C98A1E`，用量 ≤ 5%。图片：证据位零素材期用同一套单线 SVG 占位标 `[待确认]`，不用图库图、不用渲染图冒充。

个性化抓手四条（来源 → 事实 → 决定）：
1. 产品几何与工艺 → 内六角圆柱头为第一品类，发黑 / 达克罗（第 2 项，F6、F7）→ 内六角截面做全站 SVG 母题，螺纹节距做分隔线，色板取表面处理，型号串等宽四段对齐。
2. 公司数字 → 自有热处理 + 100% 光学全检 + IATF + 15 天出样；台数不是差异点（F3–F5、F9；研究简报三节）→ 首屏讲「in-house + 100% sorted」，Counter 固定四数，台数只进 About 设备表。
3. 市场审美 → 德国第一，本土站一句话一键、白底、无电话无 WhatsApp（第 4 项；研究简报四节）→ 首屏参数卡先行，CTA 用 Request a Quote，首页 5 内容块 + 2 CTA，饱和度降一档。
4. 参考站 → bossard「找东西方便」、德国站「每个型号有图纸」（第 10 项；研究简报 C1）→ 导航按标准号分组、目录页左筛选右表格、型号页「线稿 + 属性表 + 三栏下载 + 替代品」、导航常驻型号搜索。

字体：标题 Manrope 700 / 600，正文 Manrope 400（16–18px），点缀 IBM Plex Mono 500 只用于型号、参数数字、Counter、证书编号、步骤序号；阶梯 14 / 16 / 18 / 24 / 32 / 48 / 64；深底正文加一档、`#F5F5F5`；参数表 `tabular-nums`；自托管 woff2 ≤ 300KB，保留德语、波兰语字符。

参考类型：德国工厂官网式首页（一句话一键大留白）；工业分销商的属性表型产品页；瑞士网格 About（设备表 + 工艺链 + 时间轴）。
