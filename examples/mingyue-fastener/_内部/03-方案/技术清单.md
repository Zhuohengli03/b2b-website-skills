# 技术清单 · 铭岳紧固件（示例）

> 产出方：策划。读者：前端、后端。所有常规展示技术只从 `b2b-site-diagnosis/references/展示技术清单.md` 选；组件与库名以 `references/组件与特效.md` 为准。栈：**WordPress**（任务分派：业务员要能自己加一个产品；没人会改后台）→ 只用 WordPress 区块 + 轻量 JS 库，不指定 React 组件库。
> 硬约束：LCP ≤ 2.5 s（海外办公室桌面为主）；关键文字（定位句、参数表、下载链接）全部在真实 DOM；动效只为把视线引到证据与询盘入口；动效脚本总量 ≤ 100KB（本站目标 ≤ 30KB）；全部动效尊重 `prefers-reduced-motion`。

## 一、要做的

| 技术 | 用在哪个页面 | 解决什么问题（效果 + 好处） | 素材要求 | 成本档 |
|---|---|---|---|---|
| 可筛选产品目录 | Products 目录页、4 个分类页 | 上千规格按 Standard / Thread / Length / Property class / Surface / Application 实时过滤，采购 30 秒内找到型号 | 首期 30–50 个代表型号数据（D18）；全量 CSV 导入 | 中 |
| 参数表切换（Tabs） | 型号页 | Specifications / Downloads / Alternatives 三个标签，参数在首屏不折叠，下载与替代品不抢戏 | 参数数据；图纸线稿 SVG | 低 |
| 粘性询盘条 | 全站 | 手机底部 56px「Request a Quote」常驻，桌面用导航栏按钮；不占版面的第 4 个入口 | 无 | 低 |
| Mega menu（多列文字分组） | 导航 Products | 4 个标准件类 + Custom 入口 + 「Browse all / search by standard」按标准号分组，文字型不放缩略图 | 无 | 低 |
| 数字滚动计数器（Counter） | 首页 H3、About | 四个有出处的数字进视口滚一次：100% sorted / 15-day samples / 180M pcs / IATF 16949 `[待确认]` | 需求单 F4、F5、F9 | 低 |
| Bento 网格 | 首页 H3（能力总览一块，全站仅此一处） | 工艺链四步 + 四个 Counter 拼一屏，每格只讲一件事 | 线稿 SVG | 低 |
| 滚动渐入（fade-up，一次触发） | 首页分类卡、Bento 格、Custom 流程步；内页不加 | 卡片依次出现把视线按顺序带过证据；每页错落 ≤ 8 个子元素 | 无 | 低 |
| 悬停卡片（轻） | 分类卡、FAQ 卡 | 2px 上移 + 边框变深，150–200ms，只动 transform / opacity | 无 | 低 |
| 粘性侧栏（筛选栏） | Products 目录页桌面端 | 左侧筛选栏跟随滚动，右侧列表翻页不丢筛选状态 | 无 | 低 |
| 产品载体场景段（本表外例外项，只登记） | **有 · 降级为零素材原语**；放首页 H3 工艺链段 | 载体 = DIN 912 M6×20 线稿（D2 默认）；滚动时 `clip-path` 揭示 + 四步 `opacity` 逐项点亮；拿到俯视原图后换图不动版面（升级口） | 零素材期 SVG；升级需 1 张俯视原图（素材清单补拍第 1 条） | 低（具体动法由设计在 G2 定） |

首页动效类型计数：滚动渐入 + Counter + 场景段 = 3，到上限；其余页面 ≤ 2。全站钉点 0 处，脉冲 / 呼吸动画 0 处（WhatsApp 按 D9 隐藏，不占这一额度），自动播放 0 处。

## 二、刻意不用的（写给你看的理由）

| 技术 | 不用的原因 | 二期条件 |
|---|---|---|
| 视频首屏 | 零素材；德国 4 家本土站首屏均静态（研究简报四节）；你「不要会动的」 | 2 分钟车间视频收到并剪到 ≤ 10 s、≤ 4MB 后可换首屏右侧参数卡的背景——位置不变 |
| 遮罩穿透 / 光标透视 | 没有成对素材；触屏失效 | 不计划 |
| 图片序列擦洗 | 无 60–200 帧渲染或拍摄；标准件参数比外形重要 | 不计划 |
| 360° / 3D 查看器 | 无 3D 模型；加项未表态、默认不加（D10）；标准件靠参数选 | 公司有 STEP 文件且决定加 3D 时，只给非标案例件做 |
| 热点标注图 | 无实拍可标 → 按 SKILL 规则改成参数表 + 线稿标注 | 车间图到位后可在 About 设备图上加 ≤ 5 个点 |
| 滚动钉点叙事 | 你明确不要「花里胡哨会动的」；Custom 流程用静态编号步骤已够清楚；手机端易失控 | 不计划 |
| 视差、横向滚动、页面过渡、动态文字、自定义光标、WebGL | 全部是品牌站 / 创意站手法；询盘站增加等待感、影响抓取；德国采购会困惑 | 不计划 |
| Logo 跑马灯 | 合作买家的 logo 无授权（D5）；德国本土站首页不放买家 logo（研究简报二节共性 1） | 两家案例买家书面授权后，放在 About 案例段而非首页跑马灯 |
| 轮播（首页 hero） | 国内站模式；首屏只说一句话 | 不计划 |
| 交互式地图 | 「出口 23 国」不是差异点（研究简报三节）；买家集中在德波 | 不计划 |
| Lottie / Rive | 流程用静态线稿 + 编号已够；避免「图标代替照片」 | 不计划 |
| 玻璃拟态、暗色模式 | 白底是德国基线；深底只给页尾 CTA 一处且是设计层面不是技术 | 不计划 |
| 证书徽章墙、浮窗客服、滚动公告 | 你的旧站要去掉的东西（需求单第 10 项）；研究简报八节对照表 | 永久不做 |

## 四、给后端单独标出的项

- **询盘链路**：表单 → `sales@mingyue-fastener.com`（阿里企业邮箱，SMTP 发信）→ 站内备份（WP 数据库 + 可导出 CSV）→ Thank-you 页（含 GA4 转化事件）；Outlook 收件实测。
- **CMS 字段（product）**：model_string（主键，= URL slug，如 `din912-m6x20-12-9-bo`）/ standard_din / standard_iso / category / thread / length / property_class / material / surface / salt_spray_h / tensile_mpa / inch_equivalent（可空）/ drawing_svg / datasheet_pdf / alternatives（同规格换表面处理）；分类法 6 维。批量导入模板按此字段出 `交付/导入模板.csv`。
- **下载区文件类型**：PDF（证书、数据表、3.1 脱敏样本）；STEP 预留字段不首期上传（D12）。证书公开尺度按 D11：证书公开 + 3.1 样本公开 + 按型号索取按钮。
- **多语言**：首期英文单语；只预留语言切换器 UI 与 hreflang 结构 en / de / pl，不建语种（D10、D15）。
- **搜索**：原生搜索限定 product，匹配 model_string 与 standard 字段。
- **分析**：GA4 + GSC 基线；转化事件 = 表单提交、证书下载、3.1 索取。
- **性能**：字体自托管 ≤ 300KB；首屏零 JS 依赖；SVG 内联；图片位预留 webp ≤ 300KB（载体图例外位）。
- **后台可维护**：业务员加一个产品 = 填一张表单（上述字段）+ 上传线稿 / PDF，不碰主题设置。

## 五、CTA 与区块节律检查
