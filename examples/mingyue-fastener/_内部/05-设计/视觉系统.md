# 视觉系统 · 铭岳紧固件（示例）· design token

> 产出方：设计（`b2b-ui-designer`）。读者：前端（整段 `:root` 可直接粘贴）、测试。依据：`视觉方向单.md`（G2 已过闸）、`b2b-ui-designer/references/设计令牌架构.md` 三层结构。
> 规则一句话：**组件只认第三层，第三层只认第二层，第二层只认第一层，页面样式里不出现任何裸 hex。** 设计稿 `设计稿/home.html`、`model.html` 已按此写，`:root` 之外搜不到 `#xxxxxx`。
> 暗色模式：技术清单第二节「刻意不用」，本站不做；语义层只有一套映射。若二期要做，只改第二层。

## 二层 · 语义 semantic（唯一有含义的一层；bg / on-bg 成对）

| 用途 | 底 | 压在上面的字 | 对比度 |
|---|---|---|---|
| 页面 | `--color-bg` = white | `--color-on-bg` = gray-900 | 16.9:1 |
| 交替区块 | `--color-bg-alt` = gray-50 | `--color-on-bg-alt` = gray-900 | 15.5:1 |
| 卡片 / 表面 | `--color-surface` = white | `--color-on-surface` = gray-900 | 16.9:1 |
| 主色 | `--color-primary` = blue-600 | `--color-on-primary` = white | 11.3:1 |
| 主色悬停 / 按下 | `--color-primary-hover` = blue-700 / `--color-primary-active` = blue-900 | white | 12.2 / 14.3:1 |
| 主色浅底 | `--color-primary-soft` = blue-50 | `--color-on-primary-soft` = blue-600 | 9.7:1 |
| 深底（页尾 CTA） | `--color-inverse` = blue-900 | `--color-on-inverse` = off-white；`--color-on-inverse-muted` = blue-100 | 13.1 / 10.3:1 |
| 次要 | `--color-muted` = gray-50 | `--color-on-muted` = gray-500；`--color-text-secondary` = gray-500 | 5.7:1（白底 6.25） |
| 边框 | `--color-border` = gray-300（装饰性分隔、卡片）/ `--color-border-strong` = gray-400（输入框等可交互描边，3.39:1）/ `--color-border-subtle` = gray-100 | — | — |
| 焦点圈 | `--color-ring` = blue-600 | — | 2px + 外扩 2px |
| 强调 | `--color-accent` = straw-500（标签底 / 线）；`--color-accent-text` = straw-700（文字） | `--color-on-accent` = gray-900（5.74:1） | 文字白底 4.21:1 |
| 线稿 | `--color-line-art` = gray-300（描边 1.5px，示意图）/ `--color-line-art-strong` = gray-500（图标、尺寸标注文字）/ `--color-line-art-fill` = gray-900（载体最终态实体） | — | — |
| 成功 / 警告 / 错误 / 信息 | `--color-success-bg` + `--color-success` + `--color-on-success`（warning / danger / info 同构） | | 见一层 |
| 审稿标注 | `--color-review-bg` = amber-50、`--color-on-review` = amber-800、`--color-review-border` = amber-600 | | 7.54:1；**上线前随 `[待确认]` 清零** |

对比度结论：正文与背景全部 ≥ 4.5:1；大标题 ≥ 3:1；强调色文字只以 straw-700 出现在 ≥ 24px 粗体（4.21:1）；straw-500 不作文字色。

## 可直接粘贴的 `:root`

与 `设计稿/home.html` 第 0 节逐字一致（前端以 HTML 文件中的块为准，这里不重复 90 行）。摘要：

```css
:root{
  /* 一层 */
  --gray-50:#F4F5F7; --gray-300:#A9AFB7; --gray-400:#868C94; --gray-500:#5B6169; --gray-900:#1B1D21; /* …全 11 级见 home.html */
  --blue-50:#E8EEF7; --blue-600:#143A6E; --blue-700:#123565; --blue-900:#0E2A52;                     /* …全 11 级见 home.html */
  --straw-500:#C98A1E; --straw-700:#A8700F; --white:#FFFFFF; --off-white:#F5F5F5;
  --amber-50:#FFF4D6; --amber-600:#B4600E; --amber-800:#7A3F05; /* green / red 同构 */
  --space-1:4px; --space-2:8px; --space-3:12px; --space-4:16px; --space-5:24px; --space-6:32px; --space-7:48px; --space-8:64px; --space-9:96px; --space-10:128px;
  --text-sm:14px; --text-base:16px; --text-md:18px; --text-lg:24px; --text-xl:32px; --text-2xl:48px; --text-hero:56px; --text-3xl:64px; --text-table:15px;
  --font-sans:"Manrope",system-ui,-apple-system,"Segoe UI",Roboto,Arial,Helvetica,sans-serif;
  --font-mono:"IBM Plex Mono",ui-monospace,"SF Mono",Consolas,Menlo,monospace;
  --radius-sm:2px; --shadow-0:none; --dur-base:180ms;
  /* 二层 */
  --color-bg:var(--white); --color-on-bg:var(--gray-900);
  --color-primary:var(--blue-600); --color-on-primary:var(--white);
  --color-inverse:var(--blue-900); --color-on-inverse:var(--off-white);
  --color-border:var(--gray-300); --color-border-strong:var(--gray-400); --color-ring:var(--blue-600);
  --color-accent:var(--straw-500); --color-accent-text:var(--straw-700); --color-on-accent:var(--gray-900);
  /* 三层 */
  --btn-primary-bg:var(--color-primary); --btn-primary-fg:var(--color-on-primary);
  --input-border:var(--color-border-strong); --input-border-focus:var(--color-primary);
  --table-head-bg:var(--color-primary-soft); --table-zebra:var(--color-bg-alt);
}
```
