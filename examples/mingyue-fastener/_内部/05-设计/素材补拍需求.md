# 素材补拍需求 · 铭岳紧固件（示例）

> 产出方：设计。读者：PM（在停点汇总后交给你拍；本 demo 同步记入 `待用户决定.md` D29）。与 `01-需求/素材清单.md` 第四节的区别：这里按**设计稿上的图位**逐张写——放在哪、什么比例、怎么拍、到了之后谁换。每张都有固定容器，图到后原位换图、不重排版面。
> 传输要求（所有条目通用）：放进 `_内部/00-资料/` 的必须是**原图**（手机传电脑用数据线、邮件 / 网盘，微信要点「原图」），不开滤镜，不用变焦；带平台水印、网图、同行图一律不用。

## 第 1 条 · 产品载体图：一张，15 分钟，手机可拍（单独先拍，排第一）

| 项 | 内容 |
|---|---|
| 用在哪 | 首页 H3「From Wire to Sorted Part, In-House」载体大格（`设计稿/home.html` `.carrier`）；全站唯一一处你和采购都会记住的东西 |
| 拍哪一件 | **DIN 912 / ISO 4762 M6×20 12.9 发黑**（`DIN912-M6x20-12.9-BO`，D2 / D27 默认；若跑量最大的是别的型号，在 D27 里改，但首屏参数卡与型号页样本要一并换） |
| 到位后 | 设计做 L2：去背、拉直、统一到白底，像素不动；替换线稿，揭示与尺寸线点亮照跑，文字与位置不动（D28 默认换实拍，线稿保留为分类图标与型号页图纸） |
| 自验 | 背景干净、产品边缘与背景分得开；产品完整在画面里、四周留一圈空；放大看螺纹清楚；单张 ≥ 2MB 或短边 ≥ 2000px；**正上方俯视，不是斜拍** |

拍摄卡（给你或车间主任照着拍）：

> 请拍一张产品照，就一件产品，15 分钟能搞定，手机拍就行。
>
> 拍哪一件：DIN 912 M6×20 12.9 级发黑内六角圆柱头螺钉（如果跑量最大的不是这个，在 D27 里改成哪个）
>
> 怎么拍：找一张 A2 白卡纸或者一块白布，铺在窗边的桌上。白天拍，靠窗，让光从产品侧面斜进来，不要正对太阳，**不要开闪光灯、不要用台灯**。产品放中间，手机举到正上方拍俯视，镜头对准中心别歪。手机开最高画质，不开滤镜，**不要用变焦，人走近一点**。拍七八张，每张稍微挪一下位置。
>
> 放进 `_内部/00-资料/` 的时候请放**原图**——从手机传到电脑用数据线、邮件或网盘，微信传要点「原图」那个勾。压缩过的就用不了了。
>
> 发黑件表面有一点反光，在窗户和产品之间挂一张白纸挡一下，反光会柔和很多，出来好看得多。
