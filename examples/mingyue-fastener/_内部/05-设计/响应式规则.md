# 响应式规则 · 铭岳紧固件（示例）

> 产出方：设计。读者：前端、测试。手机优先，断点 **640 / 1024 / 1280**；设计稿排了 1440（桌面）与 390（手机）两档，768 为中间态自检。原型实测（Chromium，system-ui 兜底字体）：三档均无横向溢出。

## 断点与版心

| 断点 | 页边距 | 版心 | 区块上下间距 | 说明 |
|---|---|---|---|---|
| < 640（手机，设计基准 390） | 16px | 流体 | 48px | 单列；底部 56px 粘性询盘条；导航折叠 |
| ≥ 640（平板竖） | 32px | 流体 | 64px | 两列网格开始出现 |
| ≥ 1024（桌面小） | 48px | ≤ 1240px | 96px | 完整导航；12 栏网格；粘性条隐藏 |
| ≥ 1280（桌面，设计基准 1440） | 48px | 1240px | 96px | 只放宽首屏栏距；不再增大字号 |

## 触摸与可达

- 可点目标 ≥ 44 × 44px：导航项 72px 行高、汉堡 44px、按钮 48px、Tabs 48px、表格可点行 42px（整行可点，宽度补足面积）。
- 手机端悬停态不生效：卡片与行用按下态（底色）反馈；焦点圈在所有断点一致。
- 表单输入 16px，防 iOS 聚焦缩放。
- 横屏手机（≥ 640 宽）按平板规则走，不单独处理。

## 动效按断点

| 动效 | ≥ 1024 | < 1024 |
|---|---|---|
| 滚动渐入（分类卡、Bento 格、Custom 流程步） | fade-up 20px / 450ms / 错落 80ms / 一次触发，每页错落 ≤ 8 | 同左，错落 ≤ 5 |
| Counter | 进视口滚一次 ≤ 2s | 同左 |
| 载体场景段 | 四帧 scrub | 降强度（见上表） |
| `prefers-reduced-motion: reduce` | 全部关闭；载体停第 4 帧；Counter 直接显示终值 | 同左 |

首页动效类型 = 3（渐入 + Counter + 场景段），到上限；内页 ≤ 2；全站钉点 0、脉冲 0、自动播放 0、弹窗 0、preloader 0。

## 测试要点（给 QA）

1. 390 / 768 / 1440 三档 `document.documentElement.scrollWidth` 等于视口宽（无横向滚动）；原型已过。
2. 手机参数表：首列固定、可横滚、滚动条可见（iOS 需 `-webkit-overflow-scrolling: touch`）。
3. 手机首屏：H1 ≤ 3 行（当前文案 4 行，待文案回流后复验）、主按钮在首屏内、粘性条不遮住页尾 CTA 的邮箱链接（页尾区底部留 56px 余量）。
4. 导航下拉键盘可达（Tab 进入 Products 后面板打开，Esc 关闭）。
5. 字体回退：Manrope / Plex Mono 未加载时 system-ui / Consolas 下版式不破（原型即在回退字体下排的）。
