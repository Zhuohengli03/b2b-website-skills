## 3 · 四个元件（文字描述，不出画面）

- **按钮三态**（主按钮全站一个样式、一个文案 Request a Quote）：默认 = 实心 `#143A6E` 白字，高 48px、内距 24–32px、圆角 2px、无阴影；悬停 = 底色压暗 8%（≈ `#123565`），180ms，只动颜色；按下 = `#0E2A52` + 下移 1px。聚焦圈 2px `#143A6E` 外扩 2px。次按钮 1px `#143A6E` 描边、悬停底 `#E8EEF7`；三级 = 文字 + 箭头。深底（页尾 CTA）上主按钮反转为白底深蓝字。
- **卡片**（分类卡 / FAQ 卡）：白底、1px `#A9AFB7` 边框、圆角 2px、无阴影；左上 48px 单线线稿图标（内六角截面母题）；标题 18px 600；下方型号串 Plex Mono + 两个关键参数 14px `#5B6169`；悬停 2px 上移 + 边框变 `#143A6E`。整卡可点。

## 4 · 产品载体（只写文字；推导按 `产品载体与场景段.md` 三来源 × 三步）

**哪件实物**：**DIN 912 / ISO 4762 M6×20 12.9 发黑内六角圆柱头螺钉**（型号串 `DIN912-M6x20-12.9-BO`）。三来源交叉：① 采购装进自己产品里的那一件 = 标准件本身，不是设备不是厂房；② 跑量最大的型号 = 待用户决定 D2，默认取需求表代表型号第一条；③ 拍得出来的 = 目前无（L4）。同一个型号串贯穿首屏参数卡 → H3 载体 → 型号页样本 1，全站只认一件产品。

**它自己会做什么动作**：在客户车间里，这颗螺钉**从一段线材被做出来**——冷镦出头与杆 → 搓出螺纹 → 网带炉淬火回火到 12.9 并发黑 → 光学筛选逐件量尺寸。过程发生在这件东西身上 → **物型**，不是路径型（路径型要每站一张车间图，零素材下走不通）。

**滚动里怎么动**：载体是一张俯视 / 正视单线线稿（描边 `#A9AFB7` 1.5px），占首页 H3 Bento 的大格；滚动把它**沿长度方向分四段揭示**（`clip-path`）：光杆坯 → 头部成形（出现内六角截面）→ 螺纹线逐圈出现 → 整体由描边线稿填成发黑实体 `#1B1D21`；第四段**点亮尺寸线 d / k / s 与「✓」**（`opacity`）——光学筛选做的就是量这几个尺寸。每揭示一段，右侧对应工艺步（Cold heading / Thread rolling / In-house heat treatment / 100% optical sorting）与 Counter 同步点亮。载体扮演的角色 = **度量尺 + 进度**：它的长度就是工艺链，读到哪一段它就长到哪一段。原生 CSS 滚动时间轴 / IntersectionObserver，零库、不钉住（技术清单：全站钉点 0 处）；手机端保留只降强度；`prefers-reduced-motion` 时停在最终态（完整线稿 + 四步全亮）。

**放在哪一段**：**首页 H3「From Wire to Sorted Part, In-House」**（工艺链 + 数字 Bento）。首屏保持静态（工厂站不放首屏）；全站只此一段。

**素材判定与降级**：载体图 L4（素材清单 M18）。**降级：零素材原语，母题用内六角截面 SVG 线稿**（L3 示意图，标明为示意；对紧固件线稿本身是主动可选项，不是将就）。**升级口**：这一段现在用零素材线稿方案。如果后面拿到一张 DIN 912 M6×20 的俯视原图（补拍清单第 1 条，15 分钟手机可拍），这一段可以直接换成产品本身——沿长度揭示与尺寸线点亮照旧跑在实拍上，位置和文字都不用动。

**三问自检**：换成另一家客户的产品还成立吗 → 不成立（自攻钉要渗碳、锚栓不过光学筛选，四段都要重写）；这个动作在客户车间真的会发生吗 → 会，就是 F3 / F4 的工艺链；采购看到会说「对，就是这么做的」吗 → 结构工程师认得冷镦 + 搓丝 + 回火 + 尺寸检，会。

## 7 · 一句话：为什么这个方向适合这家公司

对上四项输入里的**全部四项**：客户类型是生产型工厂（叙事讲工艺链，不讲库存）→ 产品是 DIN / ISO 标准件、按标准号与参数选（型号串、参数表、线稿当主角，色板直接取表面处理）→ 目标市场德国第一（白底、单一深蓝、数字型信任、首屏静态、CTA 克制）→ 素材全部 L4（排版驱动 + 线稿母题撑住，证据位占位 `[待确认]`，图到后换图不重排）。换成一家做自攻钉或锚栓的厂，色板、母题、载体段、首屏参数卡四样都要重写——这版不成立，所以它是这家公司的。
