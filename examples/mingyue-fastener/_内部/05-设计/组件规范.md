# 组件规范 · 铭岳紧固件（示例）

> 产出方：设计。读者：前端（按此实现）、测试（按此验）。色值一律引用 `视觉系统.md` 的 token，这里不写 hex。
> **七个有状态组件 × 六态**（默认 / 悬停 / 聚焦 / 按下 / 禁用 / 加载）。状态优先级：禁用 > 加载 > 按下 > 聚焦 > 悬停 > 默认。
> 悬停只做一件事（颜色或位移二选一），150–200ms，只动 transform / opacity / color；触摸设备上悬停不生效，所以按下态与聚焦态必给。所有过渡包在 `@media (prefers-reduced-motion: reduce)` 里关掉。
> 页脚、Tabs、Counter、CTA 区、Bento、下载区属版式组件，只给尺寸与间距（第八节），不套六态。

## 1 · 按钮（三级：主 / 次 / 文字箭头；深底反转一种）

全站主按钮一个样式一个文案 **Request a Quote**（唯一例外：Quality 页页尾与型号页次按钮 Request 3.1 Certificate）。高 48px（导航栏内 40px）、内距 0 32px、圆角 2px、无阴影、字 16px 600、触摸目标 ≥ 44px、加载态不改变宽度。

| 状态 | 主（实心） | 次（描边） | 文字箭头 | 深底反转（页尾 CTA） |
|---|---|---|---|---|
| 默认 | 底 `--btn-primary-bg`，字 `--btn-primary-fg`，边 = 底 | 底透明，1px `--btn-secondary-border`，字 `--btn-secondary-fg` | 字 `--color-primary` 600 + 16px 箭头 | 底 `--btn-inverse-bg`，字 `--btn-inverse-fg` |
| 悬停 | 底 `--btn-primary-bg-hover`（压暗 8%），180ms，只动颜色 | 底 `--btn-secondary-bg-hover` | 箭头右移 2px，150ms；文字不变色 | 底 `--btn-inverse-bg-hover` |
| 聚焦 focus-visible | 外圈 2px `--color-ring`，外扩 2px（深底上外圈用 `--color-on-inverse`） | 同左 | 同左 | 外圈 `--color-on-inverse` |
| 按下 active | 底 `--btn-primary-bg-active` + 下移 1px | 底 `--color-primary-soft` + 下移 1px | 箭头回位 | 下移 1px |
| 禁用 | 不透明度 `--btn-disabled-opacity`（.4），`cursor:not-allowed`，不响应悬停 | 同左 | 同左 | 同左 |
| 加载中 | 文字换为「Sending…」+ 左侧 16px 单线旋转图标，`aria-busy="true"`，按钮禁用、**宽度锁定为加载前宽度**（防抖动与重复提交） | 不出现加载态（次按钮不提交） | — | 同主按钮 |

## 2 · 输入框（含型号搜索框、表单字段、下拉选择、文件上传）

高 48px（导航搜索 40px）、内距 0 16px、字 16px（手机不得低于 16px，防 iOS 缩放）、圆角 2px、单列。标签在上 14px 500 `--form-label-fg`，间距 8px；帮助文字 14px `--form-help-fg`。

| 状态 | 值 |
|---|---|
| 默认 | 底 `--input-bg`，字 `--input-fg`，1px `--input-border`（gray-400，3.39:1），占位 `--input-placeholder`；型号搜索框用 `--font-mono` 14px、占位 `DIN912-M6x20` |
| 悬停 | 边框 `--color-on-bg` |
| 聚焦 | 边框 `--input-border-focus` + 外圈 2px `--color-primary-soft`（`box-shadow`），`outline:none` 仅在此替代存在时允许 |
| 按下 | 同聚焦（输入框无独立按下态） |
| 禁用 | 底 `--color-muted`，字 `--color-on-muted`，不透明度 .6，`cursor:not-allowed` |
| 加载中 | 只用于搜索框异步建议：右侧 16px 旋转图标，输入可继续 |
| 错误（附加） | 边框 `--input-error-border`，下方 14px `--form-error-fg` 提示紧邻字段，`aria-describedby` 关联；提示文字写具体原因（"Enter a valid email"），不写 "Invalid" |

## 3 · 卡片（分类卡 / 证书卡 / FAQ 卡）

白底、1px `--card-border`、圆角 2px、无阴影、内距 24px；整卡可点（`<a class="card">`），内部不再嵌第二个链接。分类卡 = 48px 线稿图标 + 名称 18px 600 + 标准号 `--font-mono` 14px `--color-primary` + 两个关键参数 14px `--color-text-secondary`。图位比例固定：证书缩略 4:3（扫描件到后裁切）、产品图 4:3 或 1:1、不接受自定义比例（前端做上传校验与固定容器）。

| 状态 | 值 |
|---|---|
| 默认 | 如上 |
| 悬停 | 上移 2px + 边框 `--card-border-hover`，180ms（只有可点卡片） |
| 聚焦 | 外圈 2px `--color-ring` 外扩 2px |
| 按下 | 回到 0 位移 |
| 禁用 | 不适用（无禁用卡片；占位卡用 `.placeholder` 虚线框表达「待补」） |
| 加载中 | 骨架：标题行与两行文字用 `--color-bg-alt` 色块，1200ms 单次 shimmer；一组卡片共用一条时间线 |

## 4 · 徽章 / 标签

12px 600、全大写、字距 0.08em、内距 5px 8px、圆角 2px、不可点。两种：普通（`--badge-bg` / `--badge-fg`，如 "Representative size"）、强调（`--badge-accent-bg` / `--badge-accent-fg`，**只给「In-house」一处**）。审稿标注 `[待确认：…]` 用 `.todo`（审稿色，不是徽章，上线前清零）。

| 状态 | 值 |
|---|---|
| 默认 | 如上 |
| 悬停 / 聚焦 / 按下 | 无变化（不可交互）。若徽章做成筛选 chip（目录页），则按次按钮的四态走 |
| 禁用 | 不透明度 .4 |
| 加载中 | 不适用 |

## 5 · 参数表（型号页属性表、相关型号表、目录页列表、设备表）

`<table>` 原生；字 15px；行高 42px；表头底 `--table-head-bg`、字 600 14px、字距 0.02em、下边 1px `--table-border`；斑马纹 `--table-zebra`（偶数行）；**所有数字 `tabular-nums`**；数值列 `--font-mono` 500；**单位独立一列**（属性表）或并入表头（"Thread × length"）；数值列右对齐、表头同列右对齐（`th.num`）；属性表的键值对值列左对齐（见决策说明 D-17）；高亮行左侧 2px `--table-highlight`；不用彩色表头。手机：外层 `.table-scroll` 横向滚动，首列 `position:sticky` 固定并带底色。

| 状态 | 值 |
|---|---|
| 默认 | 如上 |
| 悬停（行） | 可点行（目录页、相关型号）底 `--table-row-hover`；不可点表无悬停 |
| 聚焦 | 可点行内的链接走链接焦点圈；整行可点时 `<a>` 铺满单元格 |
| 按下 | 行底保持 `--table-row-hover` |
| 禁用 | 占位行（D18 未到）：型号串灰字 `--color-text-secondary` + `[待确认]` 标注，不可点 |
| 加载中 | 目录页筛选刷新：表体 5 行骨架，表头不动；`aria-busy` 在 `<table>` 上 |

## 6 · 导航（顶栏 + Products 下拉 + 手机汉堡 + 手机底部粘性条）

顶栏高 72px、白底、底边 1px `--nav-border`、`position:sticky`；左 logo 位 36px 高（字标占位 `[待确认：logo 源文件]`，.ai 到后换图不改高度）；一级 6 项 14px 500；右侧型号搜索框 160×40 + 主按钮 40px。Products 下拉：**多列文字分组**（By standard / To your drawing / All），真实 DOM，宽 720px，无缩略图。手机（< 1024）：汉堡 44×44 描边按钮，菜单面板全屏白底、一级项 48px 行高、搜索框进面板顶部；**询盘按钮改到底部 56px 粘性条**，白底上边 1px，按钮全宽；型号页 / 分类页带 `?model=` / `?category=` 预填。

| 状态 | 一级链接 | 下拉项 | 汉堡按钮 |
|---|---|---|---|
| 默认 | `--color-on-bg`，下边 2px 透明 | 14px `--color-on-bg`，标准号 `--font-mono` 12px 次要色 | 描边 1px `--color-border` |
| 悬停 | 字 `--nav-link-active`；Products 悬停 / `focus-within` 打开下拉（打开延迟 0，关闭延迟 150ms 防误触） | 字 `--color-primary` + 强调色下划线 | 边框 `--color-on-bg` |
| 聚焦 | 外圈 2px `--color-ring` | 同左 | 同左 |
| 按下 | 字 `--color-primary-active` | 同左 | 底 `--color-bg-alt` |
| 当前页（替代「禁用」） | 字 `--nav-link-active` + 下边 2px `--nav-link-active`，`aria-current="page"` | 当前项加粗 600 | 打开态图标换 ×，`aria-expanded="true"` |
| 加载中 | 不适用（导航无异步） | — | — |

## 7 · 询盘表单（Contact 页主体；型号页 / 分类页 / Custom 页带预填）

单列、最大宽 560px、字段间距 24px；必填 3 项（Name / Email / Message），可选 Company / Country / Standard & size（预填型号）/ Quantity / 附件（PDF、STEP ≤ 10MB）；主按钮全宽（手机）或右对齐 200px（桌面）；蜜罐字段 `website`（绝对定位移出视口，`aria-hidden`、`tabindex=-1`）；提交后跳 Thank-you 页。

| 状态 | 值 |
|---|---|
| 默认 | 字段按「输入框」默认态；必填标 `*` 在标签后，颜色 `--color-danger` |
| 悬停 | 字段按输入框悬停态 |
| 聚焦 | 字段按输入框聚焦态；首个错误字段在提交失败后自动聚焦 |
| 按下 | 提交按钮按主按钮按下态 |
| 禁用 | 提交中整表 `fieldset[disabled]`，字段按输入框禁用态 |
| 加载中 | 提交按钮进入加载态（宽度锁定、Sending…），按钮上方不出现进度条；成功 → 跳转；失败 → 表单顶部 `--color-danger-bg` 条 + `--color-on-danger` 文字，`role="alert"`，并保留已填内容 |

## 8 · 版式组件（只给尺寸与间距）

| 组件 | 规格 |
|---|---|
| 页脚 | 4 栏（2fr 1fr 1fr 1fr）；14px；栏标题全大写 0.08em；logo 44px；证书一行文字；底部版权行；上边 1px；内距 48px |
| Tabs（型号页） | 下划线式；标签 48px 高、16px 600、间距 24px；当前态字 `--color-primary` + 下边 2px；键盘可达（原型用 radio + label，前端按 Kadence Tabs） |
| Counter | 数字 `--font-mono` 600，64px（≥1024）/ 48（≥640）/ 40（手机），行高 1.05；后缀 60% 字号 500 次要色；标签 14px 全大写 0.08em；进视口一次 ≤ 2s；**DOM 里留真值**（`<span aria-hidden>0</span><span class="sr-only">100%</span>` 模式） |
| Bento（首页 H3 唯一一处） | 12 栏、间距 16px；格 1px 边框无阴影、内距 24px；载体格 7 栏 × 2 行；步骤格 5 栏 × 2 行；车间图位 6 栏 × 2 行；Counter 格 3 栏 |
| CTA 区（中段） | 白底 1px 边框条，内距 32px，标题 24px，两栏（文 / 按钮） |
| CTA 区（页尾） | 深底 `--color-inverse`，内距 64px 上下，标题 32 / 48px 700 白，正文 17px 500 行高 1.7 `--color-on-inverse`，主按钮反转白底；高度随内容（≈ 280–320px） |
| 下载区（三栏） | 每栏 1px 边框卡，栏标题 18px 600 + 20px 线性图标；每项一行：文件名 / 类型与大小（mono 14px）；未到显示「PDF coming」+ `[待确认]`，不放坏链接 |
| 占位框 `.placeholder` | 1px 虚线 `--color-border-strong`、底 `--color-bg-alt`、居中内六角母题 40–48px + `[待确认]` + 一行拍摄要求；比例随图位（4:3 / 3:4） |
| 螺纹节距分隔线 | 高 8px、间距 8px 的 1.5px 竖线（SVG pattern `#pitch`），色 `--color-line-art`；只用于区块之间，不替代卡片边框 |
| 线稿 / 母题 | 内联 SVG，描边 `--color-line-art` 1.5px、尺寸线 1px、隐藏线 `4 3` 虚线；标注文字 `--font-mono` 11px `--color-line-art-strong`；`<title>` 写型号串；每个 ≤ 10KB |
