**三条共性**（德 / 瑞 / 波 / 美 7 家）：
1. 没有一家在首页放证书徽章墙或买家 logo 跑马灯（仅 Marcopol 放买家 logo）；信任靠**数字 + 栏目**（库存件数、供货率、面积、实验室），证书放二级页 [观察]。→ 对我们：证书放「Quality」二级页 + 下载区，首页放数字。
2. 产品页以**标准号为主键**（ISO 4762 / DIN 912 并列，注明 DIN 已撤回、ISO 替代；细牙 ISO 12474），属性 = 标准 / 材料 / 等级 / 表面 / 头型 / 驱动 [观察 C1、C5]。→ 对我们：型号页字段按这套摆，DIN 与 ISO 号并列。
3. 没有一家用 WhatsApp、浮窗客服、滚动公告；联系以表单 + 邮件 + 固定电话为主；德国 3 家首页甚至不放电话 [观察]。→ 对我们：隐藏 WhatsApp 不吃亏（与 D9 默认一致），表单 + sales@ 邮箱 + 电话足够。

**三条差异**：
1. 工厂站（C2 Kamax、C7 Portland Bolt）讲**制造能力与工艺**，分销站（C1、C3、C5）讲**库存与物流** [观察]。铭岳是工厂，叙事对标 C2 / C7，页面找东西的体验对标 C1。
2. 美国站（C7）CTA 直接且密集（Request a Quote 全大写、电话 / 短信 / 聊天），德国站（C2–C4）CTA 克制、首页无电话 [观察]。德国优先 → 克制为基线，美国页可加「Request a Quote」。
3. 波兰站（C6）分类双轨：按行业 + 按产品组，且 7 个语种各自域名 [观察]；德国站单轨按产品 / 服务。→ 对我们：首期按产品组单轨 + 「应用行业」做筛选维度，不做行业一级导航。

## 六、给各岗位的建议

### 策划（站型、导航、必须页面）
- 站型：B2B 询盘站，叙事对标工厂站 C2 / C7（能力 + 工艺），找东西的结构对标 C1 / C5（标准号主键 + 属性筛选）。归因：业务——德国分销商的采购习惯是按标准号找 [观察 C1、C5]；体验——你点名「找东西方便」。
- 一级导航参考（英文）：Products / Custom Cold-Formed Parts（非标独立一级，利润最高）/ Quality & Downloads / About（Factory）/ Contact。不要 News 在一级（C8 有，德国 4 家都压到二级 [观察]）。
- 必须页面：5 个分类页；型号页（代表型号 30–50 个，字段：Standard（DIN+ISO 并列）/ Thread / Length / Property class / Material / Surface / Salt spray / Drawing（位）/ Downloads）；Custom 页（流程：Drawing → DFM → Tooling → Sample 15 days → PPAP → Mass production）；Quality 页（设备表 + 证书下载区 + 材质报告索取）；Contact（表单 + sales@ + 电话，无 WhatsApp）。
- 低素材可行版式：德国站首页本身就是「大标题 + 一句话 + 一张图」[观察 C2、C4]，零素材时可用参数表、线描、数字卡替代，首屏静态。

### 文案（定位句、信任数字、FAQ）
- 定位句方向：「Cold-formed fasteners to DIN / ISO and to your drawing — made in-house, heat-treated in-house, 100% optically sorted for automotive.」证据 F3、F4、F9。避免「one-stop solution」「leading」（C8 用法 [观察]，德国 4 家无一家用 leading 作首屏）。
- 信任数字（首页三到四个）：Since 2009 / 14 cold-heading lines / 180 million pcs per year / IATF 16949（`[待确认]`）。「23 countries」「40+ containers」不上首屏（第三节）。
- 表述惯例：标准号写法「ISO 4762 / DIN 912」；等级写「property class 10.9」（ISO 898-1 用语）不写 grade 10.9（grade 是 SAE 用语，美国页可括注）；表面处理写 black oxide / zinc plated / zinc flake（Dacromet 是商标，写 zinc flake coating (Dacromet-type)）；材质证明写「EN 10204 3.1 inspection certificate」。
- 合规禁语：不写 CE（紧固件不适用 CE 标志，除非建筑用 EN 15048 / EN 14399，公司品类不涉及）；不写「REACH certified」（REACH 是合规声明不是认证），写「REACH / RoHS compliant, SGS report available」。
- FAQ 选题见关键词表问题型 11 条；优先：ISO 4762 vs DIN 912 / 12.9 vs 10.9 / black oxide vs zinc / MOQ & lead time / 3.1 certificate / CBAM data availability。

## 九、给 PM 的提醒（你的自述与市场事实的冲突或缺口）

1. **展会日期**：需求单硬节点「明年 3 月 24 日斯图加特紧固件展前上线」，但官方站显示 Fastener Fair Global Stuttgart 下届为 **2027 年 4 月 6–8 日**（来源 https://fastenerfairglobal.com/ ）。3 月 24 日上线不冲突（更早），但名片印网址的时间点与展位信息请与用户核对（已追加 D14）。
2. **欧盟反倾销税与 CBAM**：德国、波兰分销商站都设了 CBAM 页 [观察 C3、C6]，欧盟对华紧固件反倾销税仍在（税率未核实）。采购会在询盘里直接问「你们适用税率多少」「能否提供 CBAM 排放数据」。建议文案在 FAQ 预留两条，并请 PM 问你是否有海关编码 / 税率 / 排放数据（已追加 D13）。
3. **「14 台冷镦机」不是差异点**：国内头部常熟标准件 400+ 台、友为 500+ 台设备（目录页）。首屏定位不要以台数取胜，用「自有热处理 + 100% 光学全检 + 15 天出样」。
4. **美国市场与品类错位**：公司主打 DIN / ISO 公制，美国本土站全是 ASTM / SAE / 英制 [观察 C7]，且「Made in USA」是卖点。建议美国保持第二优先但只做英文站通用覆盖 + 产品页 inch 对照，不做美国专页；资源倾斜给德国与波兰（与成交证据一致）。
5. **材质报告「可下载」的边界**：德国买家要求下载材质报告，但 3.1 证书是按批次出的，不可能预先全量上传；德国分销站把证书放登录后 [观察 C5]。建议「样本 3.1 报告（脱敏）可下载 + 按型号索取按钮」，需你决定公开尺度（已追加 D11）。
6. **图纸来源**：你喜欢「每个型号有图纸」，但需求表没说有 2D / STEP 文件。标准件可按 DIN / ISO 尺寸表自绘线描（设计可做），非标件图纸涉及买家保密（已追加 D12）。
7. **截图缺口**：本环境无法截图，设计的 3–5 张本土站截图需设计自截（第六节清单）。不影响判定，但要在 G2 前补齐。
