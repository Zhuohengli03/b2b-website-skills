# 任务分派 · 铭岳紧固件（示例）

> 读者：各岗位 agent。每段四项：任务 / 你的原话与意图 / 约束 / 截止日。拍板人是你本人（demo 默认确认）：需要你去翻资料、拍照片才能补的一律追加到 `_内部/待用户决定.md`（谁问 / 缺什么 / 为什么需要 / 不定就按什么推进），不各自问你，由 PM 在停点汇总一次问（最多 5 条）；截止日无日历（生产连着跑，合计约半天），硬节点为 3 月 24 日展前上线。
> 共同约束（所有岗位）：不编造数字、证书、买家名、图；用 `[待确认：X]` 占位；不用网图、不冒充；素材为零时按三级过渡预留「图到位后升级版」；旧站与国内资料只作事实来源，结构视觉叙事按德美波采购重来。

## 1. 研究员（`b2b-market-research`）→ 写 `_内部/02-研究/研究简报.md`、`关键词表.csv`

**交接载荷（六项）**
- 行业与品类：紧固件；主推 5 类——DIN 912 / ISO 4762 内六角圆柱头螺钉、DIN 6921 法兰面螺栓、非标冷镦件（按图）、自攻螺钉、汽车用 10.9 级高强度螺栓
- 产品性质：标准工业件（DIN / ISO 标号可检索）+ 非标 OEM/ODM 冷镦；12.9 / 10.9 级、发黑 / 达克罗、盐雾、IATF 16949 是行业关键证据
- 目标市场前三：德国、美国、波兰
- 买家类型：经销商 / 贸易商为主；汽车零部件厂的二级供应商采购；终端工厂
- 你给的参考站：bossard.com（喜欢：干净、找东西方便）；一家德国紧固件厂站（网址你记不住，喜欢：参数表清楚、每个型号有图纸）→ 网址待用户决定，不定则自行找 3 家德国紧固件供应商站替代
- 你自述的优势：年产 1.8 亿件；14 台冷镦机（6 台 2022 年四模四冲）；自有热处理线；3 台光学筛选机、汽车件 100% 全检；IATF 16949；非标 15 天出样；出口 23 国；德国买家年走 40 多个柜

**任务**：看 3 家德国紧固件供应商站 + bossard.com + 2 家国内头部同行英文站，拆导航结构、参数表与图纸的呈现方式、证书 / 材质报告下载的放法、非标定制页怎么写；出三张关键词表（含量级与意图分类）；出国内站 vs 本土同行差异对照表（公司旧站是 2016 年国内风格，要有依据回答「为什么不像国内站那样」）。

**你的原话与意图**：「喜欢它参数表清楚，每个型号点进去都有图纸」「bossard.com 干净，找东西方便」→ 意图是采购能快速定位型号并拿到工程数据；「不要滚动公告、领导视察照、花里胡哨会动的」→ 意图是像德国采购看惯的工程站，不像国内站。

**约束**：只用需求单事实；你提到的「德国站」拿不到网址不猜；波兰市场单独看一眼本土经销商站（成交第二多）。

**截止日**：本次运行连续跑，无日历截止。

## 2. 策划 / 诊断（`b2b-site-diagnosis`）→ 写 `_内部/03-方案/` 四份

**交接载荷（七项）**
- 公司类型：生产型工厂（自有厂房与设备，可写 Our factory）
- 产品与品类：上述 5 类；型号常规几百、按规格上千；代表型号 3 个（见需求单第 2 项）
- 买家类型：经销商 / 贸易商、汽车二级供应商采购、终端工厂
- 目标市场：德国、美国、波兰
- 素材清单状态：车间 / 产线 无（待补）；产品图 5 类均 无（待补）；证书 无（待补）；logo 无（待收）；载体图 降级留升级口；视频 无（待收）；旧站抓取 不适用
- 范围：专业摄影 / 3D / 多语言要不要加，待用户决定（D10），不定则按询盘站标准范围
- 硬节点：3 月 24 日展前上线

**任务**：定站型（PM 初判 B2B 询盘站）；站点地图到二级；首页线框逐屏并标每区块字数上限与图片数量；技术清单只从展示技术清单里选，登记产品载体场景段「无 / 降级 + 放哪一段」；风格与字体方向注明素材不支撑（零素材只能选国际企业风 / 工业硬核风 / Bento 排版型）并给四条个性化抓手。必须规划：可筛选产品目录（按分类 + 代表型号，首期 30–50 个代表产品，全量批量导入）、每个型号页带参数表与图纸位、「非标按图定制」独立页、证书与材质报告下载区、旧站三类结论（保留 / 重做 / 推倒）。

**你的原话与意图**：「产品几百个型号我们自己也没精确数过」→ 怕漏，按分类 + 筛选承载；「非标按图定制利润最高，要专门一页」→ 转化优先级最高的页面；加项（多语言、专业摄影、3D）没表态 → 首期英文单语、不加摄影与 3D（D10）；「旧站的公司简介、证书页、联系方式要保留」→ 作为素材清单一项由文案重写，不照搬；「没人会改后台，最好改内容不用碰代码」→ 结构要简单到业务员能加一个产品。

**约束**：不出高保真、不写文案；旧站不可访问不做旧站体检（RUN.md）；多语言只预留切换器不做语种。

**截止日**：本次运行连续跑，无日历截止。

## 3. 文案（`b2b-copywriter`）→ 写 `_内部/04-文案/` 三份

**任务**：按线框和需求单事实清单（F1–F16）写全站英文：定位句（首屏说清做什么——冷镦紧固件工厂、标准件 + 按图非标、汽车级品控）、产品页参数与交易条件（MOQ、交期、结算、FOB 宁波 / CIF）、About 产能证据（设备台数、年产量、认证）、OEM 流程（图纸 → 开模 → 15 天出样）、非标定制页、FAQ、CTA 与表单文案；每个数字在事实来源表里有出处。

**你的原话与意图**：「希望网站看起来正规」（隐含于「先把门面做好」「不要旧站那种」）→ 意图是信任，用产能数字和 IATF 替代形容词；「德国买家要求能下载材质报告和 IATF 证书」→ 文案里每个产品页都要指向下载区；「老板自己写的简介想留」→ 原文未到，重写并标 `[待确认：老板简介原文]`，不照搬中文思路。

**约束**：公司英文名固定 Mingyue Fastener Co., Ltd.；logo 副标 MINGYUE FASTENER · PRECISION SINCE 2009 全大写；证书、案例买家名、「40 多个柜」未有实物 / 书面确认的一律 `[待确认]`；你不一定核得了英文（需求表 38 没人会改，默认由文案负责表达）→ 事实对照表中文列给你核；每段不超过线框字数上限；不写「服务 1000+ 买家」之类无证据宣称。
