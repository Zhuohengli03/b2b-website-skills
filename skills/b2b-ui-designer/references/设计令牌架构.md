# 参考 · 设计令牌架构

「视觉系统」这份产出到底该长什么样，按这一份写。目的很实际：**前端拿到之后不用再问设计任何一个色值，以后维护网站的同事在后台改一个主色时不会把对比度改坏。**

> 三层结构改编自 [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的 design-system 参考（MIT License, Copyright (c) 2024 Next Level Builder）。已从 Tailwind / shadcn 改写为 CSS 自定义属性 + WordPress `theme.json` 的形态，并按 B2B 询盘站的场景收窄。

## 三层，不要跳层

| 层 | 是什么 | 例子 | 谁引用它 |
|---|---|---|---|
| 一 · 原始值（primitive） | 一堆没有含义的原料。只是「蓝色的第 600 号」，不代表任何用途 | `--blue-600: #1d4ed8`　`--space-4: 16px`　`--radius-sm: 2px` | 只有第二层能引用 |
| 二 · 语义（semantic） | 用途名。这一层才有含义，也是唯一会因深浅色模式而变的一层 | `--color-primary: var(--blue-600)`　`--color-bg`　`--color-border` | 第三层和页面样式 |
| 三 · 组件（component） | 某个组件的某个部位 | `--btn-primary-bg: var(--color-primary)`　`--input-border` | 只有该组件的样式 |

**跳层就是这套东西失效的开始。** 组件样式里直接写 `#1d4ed8` 或 `var(--blue-600)`，等于把这个色值钉死——换主色要全站搜替换，深色模式下必然出错。规则一句话：**组件只认第三层，第三层只认第二层，第二层只认第一层，页面里不出现任何裸色值。**

## 第一层要给全的六组

| 组 | 给到什么粒度 | B2B 询盘站的注意点 |
|---|---|---|
| 灰阶 | 9–11 级（50 到 950） | 参数表的斑马纹、边框、次要文字全靠灰阶。灰阶不够细，表格就只能靠边框撑，看起来会很脏 |
| 主色 | 5–9 级 | 从 logo 吸色定基准级，其余按明度推。**不要凭感觉给九个蓝** |
| 状态色 | 成功 / 警告 / 危险 / 信息，各 3 级（浅底、主色、深字） | 询盘表单的校验提示要用，一个 hex 不够 |
| 间距 | 4px 为基数的刻度（4 8 12 16 24 32 48 64 96 128） | 区块之间的垂直间距只能从这套里取，不许出现 37px |
| 字号与行高 | 一套模数刻度 + 每级配好的行高 | 手机端正文不得低于 16px，这是硬的 |
| 圆角 / 阴影 / 动效时长 / 层级 | 各 3–5 级 | 圆角超过三级会让页面看起来是拼的；阴影给 3 级就够，第 4 级往往是滥用 |

## 第二层的命名法

`--color-<用途>` 和 `--color-on-<用途>` 成对给。`on-` 是压在这个底色上的文字色——**成对给才能保证对比度**，只给底色不给文字色，前端会自己挑一个，然后就出现深蓝底配深灰字。

必须给全的对：`bg` / `on-bg`、`surface` / `on-surface`（卡片）、`primary` / `on-primary`、`muted` / `on-muted`、`border`、`ring`（焦点圈）、`success|warning|danger|info` 各自的 `bg` / `on-`。

## 深浅色只改第二层

第一层原始值一个都不动，只在深色模式下重新指向：

```css
:root{
  --color-bg: var(--gray-50);
  --color-on-bg: var(--gray-900);
  --color-surface: #fff;
  --color-border: var(--gray-200);
}
@media (prefers-color-scheme: dark){
  :root:not([data-theme="light"]){
    --color-bg: var(--gray-950);
    --color-on-bg: var(--gray-100);
    --color-surface: var(--gray-900);
    --color-border: var(--gray-800);
  }
}
:root[data-theme="dark"]{ /* 同上，供手动切换用 */ }
```

三条硬规则：**任何色值都必须先在 `:root` 里定义一次**，只在媒体查询里出现的变量在未标记状态下不存在，页面会用一套主题的字配另一套的底；深色底的正文字重比浅色底加一档，细字在深底上会糊；深色不是把浅色反过来，主色在深底上通常要提亮一到两级才够对比度。

## 第三层给到什么程度

只给会被复用的组件，且只给「会变的部位」。按钮、输入框、卡片、徽章、参数表、导航、询盘表单——询盘站上真正需要令牌化的就这七个。

每个组件把状态写全，这是最容易漏的：

| 状态 | 必须给 | 说明 |
|---|---|---|
| 默认 | 底色、文字色、边框、圆角、内边距 | |
| 悬停 hover | 底色或边框的变化 | 触摸设备上不生效，所以不能是唯一反馈 |
| 按下 active | 一点位移或加深 | 没有按下态，用户会怀疑没点上 |
| 聚焦 focus-visible | **焦点圈的颜色与宽度** | 必给。删掉 outline 不给替代是 P0 |
| 禁用 disabled | 降低不透明度 + 光标 | |
| 加载中 | 文字换成加载态且按钮禁用 | 询盘按钮不做这个就会有重复提交 |
| 错误 error | **边框换成 danger 主色 + 一行修复文案**（说清怎么改，不只说「无效」） | 表单类组件必给：输入框、询盘表单。只变边框不给文案，用户不知道错在哪 |
| 选中 selected | 底色或边框换成 primary，并有一个非颜色的第二标识（勾、加粗、下划线） | 筛选类组件必给：筛选 chip、Tabs。只靠颜色区分，色弱用户分不出 |

六态是七个组件都要给的；**错误与选中是表单类和筛选类的补充两态**，不给同样算缺状态（参考 ux-ui-agent-skills）。**加载态保持全色 + spinner**，不借禁用态的变暗——变暗让用户以为按钮坏了，spinner 才说明「在处理」；禁用只是逻辑上拦重复提交，视觉上不表现为禁用。

状态优先级：禁用 > 加载 > 按下 > 聚焦 > 悬停 > 默认。同时命中时按这个顺序取。错误与选中是持续态，叠加在上述瞬时态之上（选中的 chip 仍有悬停与聚焦；出错的输入框聚焦时焦点圈压在红边框上）。

## 间距层级与标题硬数

间距刻度只规定「能取哪些值」，没规定「哪里取大哪里取小」。补一条层级规则和几条标题硬数，都是前端与 QA 能直接量的。

**间距「外 > 内」。** 区块 padding > 卡片 padding > 元素间距，三级各取刻度上不同的档，**区块级要跳大档**，不是每级加 8。三级一样大，页面就没有分组，读起来是一张平铺的纸（参考 ux-ui-agent-skills）。

| 层 | 取值档 | 归因 |
|---|---|---|
| 区块之间 | 96 / 128（手机 48 / 64） | 分组靠留白不靠线 |
| 区块内 padding、卡片之间 | 24 / 32 / 48 | 同一区块里的东西要看得出是一组 |
| 卡片内 padding | 16 / 24 | 内容贴边显得挤，超过 24 显得空 |
| 元素间距（标题与正文、图与图注） | 4 / 8 / 12 | 紧才看得出属于同一个元素 |

**标题硬数**（参考 ux-ui-agent-skills；给的是范围，不是单点）：

- 区块标题 18–24 个字符（英文按字符数，不按词数），**≤ 3 行**；超了回流文案，不缩字号
- 标题行高 1.05–1.15；正文行高 1.6 不变
- 展示字号（首屏 H1、Counter 数字）**≥ 2.5× 正文字号**：正文 16 就 ≥ 40，正文 18 就 ≥ 45，取字号刻度上最近的一档（48）
- 标题级之间至少跳一档，相邻两级只差 2px（16 → 18 → 20）读不出层级

归因：体验——标题短、行高紧，采购扫读时一眼抓住名词；视觉——展示字号与正文拉开才有锚点，间距分三级页面才有分组；技术——都是数字，前端能写成 token，QA 能量。

## 怎么交出去

`视觉系统.md` 里写三张表（一层、二层、三层各一张），外加一个可直接粘贴的 `:root` CSS 块。WordPress 项目再给一份 `theme.json` 的 `settings.color.palette` 与 `settings.typography.fontSizes` 映射——这样以后维护网站的同事在区块编辑器里能选到的颜色，就只有定过的那几个，改不出对比度事故。

**交接前自检三条**：页面样式里搜不到裸 hex；每个 `--color-x` 都有配对的 `--color-on-x`；七个组件的六个状态都有值（输入框与询盘表单另有错误态，筛选 chip 与 Tabs 另有选中态）。三条都过才算「视觉系统」这份产出完成。
