# 参考 · 你在这个环节会提什么、意图是什么、怎么满足

> 从 SKILL.md 正文搬来，原文未改。设计师拿不准你的某句反馈背后要什么时读。

| 你的原话 | 背后的意图 | 怎么满足 | 归因 |
|---|---|---|---|
| “不够高端 / 不够大气” | 觉得页面像模板站、像小公司；通常指向留白不够、图片质量差、字体廉价、色彩杂 | 不加装饰，做减法：加大留白与字号阶梯、统一到两种字体、把网图换成实拍或用排版替代图片、色彩收到主色 + 一个强调色 | 视觉：层级清晰和克制是“高端”的来源；业务：模板感会让采购怀疑公司规模 |
| “首页太空了，多放点东西” | 怕采购看不到全部能力；把信息密度等同于实力 | 用 Bento 能力总览把产能、认证、交期、OEM 各占一格放进一屏；产品分类做成带图卡片；不加轮播和弹窗 | 体验：一屏内多个信息入口比一屏一个大图更高效，但要有层级；业务：能力总览是采购要的“证据”，轮播不是 |
| “首页放个大轮播图，像 XX 那样” | 见过大公司站，觉得轮播代表规模 | 解释轮播第二张起点击率不到 1%，改成一张固定 hero（车间实拍或产品打光图）+ 定位句 + 双按钮；如你坚持，最多两张且不自动播放 | 业务：首屏只能说一句话，轮播说三句等于没说；体验：自动轮播干扰阅读；技术：拖慢 LCP |
| “颜色用我们 logo 的红” | 品牌一致性，合理 | 把品牌色用作强调色（按钮、链接、图标、强调数字），主色用中性深色或深蓝承载大面积；饱和红大面积用会显得促销 | 视觉：强调色只有在少量使用时才起强调作用；业务：欧美工业采购对大面积高饱和色有“廉价促销”联想 |
| “字太小了”（通常是老板在手机上看） | 可读性诉求，往往是对的 | 正文提到 16–18px，行高 1.6；标题阶梯重排；但不把所有文字放大，否则层级消失 | 体验：可读性优先；视觉：放大要按阶梯不是整体缩放 |
| “把 logo 放大” | 品牌曝光焦虑 | logo 高度控制在导航栏 32–44px，用留白让它显眼而不是放大；页脚可放大一档 | 视觉：导航栏是工具，不是广告位；体验：logo 过大压缩导航空间 |
| “要有动效，显得有科技感” / “要有设计感” | 想和“死板的模板站”区分。这个诉求是对的，但方向常被理解错 | **不是给静态页面加一圈入场动画，是让产品本身贯穿页面**：选一件标志性实物做载体，滚动驱动它变化，内容挂在它上面（做法见 `references/产品载体与场景段.md`）。判据是「拿掉动效页面还成立吗」——一模一样就是装饰，塌了才是结构。不加粒子、不加页面过渡、不加与产品无关的抽象图形 | 业务：采购记住的是产品怎么被呈现，不是页面会动；视觉：一页只讲一件事才成立，十种效果各做一点等于没做；技术：贵的是素材不是代码，载体图不达标就降级，别硬做 |
| “和竞品长得太像了” | 差异化焦虑 | 差异靠内容和素材（真实车间、真实数字），不靠版式；版式上可用一处独特组件（例如工艺流程横向时间轴）作为记忆点 | 业务：采购不会因为版式独特而下单，会因为证据充分而询盘；视觉：一个记忆点足够 |
| “能不能加个弹窗让他们留邮箱” | 想多抓线索 | 不做进站弹窗；用粘性询盘条和页尾 CTA 代替；退出意图弹窗仅在博客页可选 | 体验：进站弹窗是采购最反感的元素之一；业务：B2B 的转化在看完证据之后，不在进站瞬间 |
| “深色背景显得高级” | 对“高级”的直觉 | 按行业判断：精密设备、LED、电子可用深色 hero；食品、纺织、化工原料保持浅色；深色只用于 hero 和 CTA 区，正文区保持浅色 | 视觉：深色适合打光产品图，不适合大段文字；体验：深色底长文可读性差 |
| “这个设计我看不懂”（面对线框或组件稿） | 你需要看到接近成品的东西才能判断 | 只给高保真：首页桌面 + 首页手机 + 一个产品详情页；用真实文案和真实素材，不用 lorem ipsum 和占位图 | 业务：确认闸要你能做决定，抽象稿做不了决定 |
