# 参考 · 输出模板（视觉方向单 · 设计决策说明）

> 从 SKILL.md「流水线接口」与「设计流程 6」搬来，原文未改。出 `视觉方向单.md`（1 页）和 `设计决策说明.md`（≤ 100 行）前读。篇幅上限：内部探索最多 3 个方向、每个方向一段 ≤ 10 行；方向单 1 页。

## 视觉方向单：方向单之前的内部探索

**方向单之前先做内部探索（不给你看）。** 直接出一版方向单，手会自动落到 AI 的默认版式（见 `b2b-site-diagnosis/references/公司分型速查与自查.md` 的「版式级 AI 味」）。先自己出 2–3 张方向卡，**每张用不同的推导引擎**：① 产品材料 × 使用环境（镀锌的冷光、注塑件的哑面、面料的垂感，以及它被装在哪里、在什么光线下被看）；② 工序场景（车间里真实发生的那段过程，推导按 `references/产品载体与场景段.md`）；③ 借别的领域的视觉语法（工程图纸、检测报告、航运单据、产品目录这类采购本来就在看的东西）。每张卡写四项：骨架（区块顺序与栏宽）、字体、色彩、主视觉。**差异检查：任两张卡在四项里最多同一项**，同了两项就是同一个方向的换色版，重出一张。**禁止按亮 / 暗分方向**——亮暗是第二层 token 的事，不是方向。然后做眯眼测试：三张卡缩到 10% 并排，还分得出哪张是哪家、各自在讲什么，才算有差异；分不出的那张淘汰。收敛成一版交 G2，另外的卡留在 `_内部/` 不进 `交付/`，你说「不是这个感觉」时拿出来对照，不从头来。**仍然只给你一版**——探索是内部的，不违反下面「不出三版让你挑」（做法参考 oil-oil/oil-ui）。归因：业务——你挑三版会挑成拼凑品，但设计师不探索会交出默认版；视觉——不同引擎推出来的方向才是真差异，换色不是。

## 视觉方向单：一页纸写什么

**第一件事是视觉方向单，不是页面。** 拿到 `风格与字体方向.md` 后先出 `视觉方向单.md`（一页纸）交 PM 过 G2 闸：色块 + HEX + 取自哪里（优先从你们公司 logo 吸色，不新造品牌色）／标题与正文字体各一行真实示例（公司英文名、一个真实产品型号）／按钮三态·卡片·参数表表头·询盘入口四个元件／**产品载体一项**（哪件实物、它自己会做什么动作、滚动里怎么动、放在哪一段——**只写文字，这一闸不出任何画面**，推导按 `references/产品载体与场景段.md` 走）。**你给的是静态参考图时，图只供版式配色字体，动作仍从产品推导**——不许因为图是静态的就不做场景段，也不许照着图里某个区块想象它的动效／参考站（从 `研究简报.md` 取 3–5 个目标市场同行，各标出「要的是这个感觉的哪一点」）／**抓手两条**（从 `风格与字体方向.md` 的四条里选至少两条，各一句写会落在哪）／一句话说明对上四项输入的哪几项。

**方向单里再加一行调性五刻度。** 能量 / 完成度 / 密度 / 分量 / 严肃度各 1–5 打点，每个点后面写一句依据（取自产品、目标市场基线或你提名的参考站）。刻度直接翻译成 token，不停留在形容词：能量 → 饱和度预算（强调色占比与饱和档）；分量 → 字重与展示字号比；密度 → 留白档（区块间距取刻度的哪一档）；完成度 → 圆角、阴影与图片精修程度；严肃度 → 字族与是否允许点缀。你说「不够高端」「太素」「不够大气」时，指着刻度谈：是哪一项要往哪边挪一格、挪了之后哪些 token 跟着变，不接「整体再大气一点」这种无法落地的话。归因：业务——把感受词变成你能选的刻度，改一次就能落地，不用反复试；视觉——「高端」在刻度上通常是低能量、高完成度、低密度，而不是加装饰。

**方向单没过闸不出任何页面**——你看到完整首页会把结构、配色、文案、图片的意见混在一起，改完是拼凑品。过闸后只出一版首页，不出三版让你挑。

## 设计决策说明：示例

示例决策说明：

| 决定 | 归因 | 理由 |
|---|---|---|
| 首屏不用轮播，用单张车间实拍 | 业务 + 体验 + 技术 | 首屏只说一句话；轮播第二张无人看；静态图 LCP 更快 |
| 产品卡显示两个关键参数 | 业务 + 体验 | 采购在列表页就能初筛，减少无效点击 |
| 参数表数字用 tabular 等宽 | 体验 | 逐行比参数时对齐才不看错 |
| About 页产能数字做成 48px Counter | 业务 + 视觉 | 数字是 About 的主角，放大才成为视觉锚点 |
| 全站圆角 4px、无阴影 | 视觉 + 业务 | 工业买家的“可靠”感来自克制；大圆角显得消费品 |
| 页尾 CTA 用品牌深蓝底白字 | 视觉 + 体验 | 收束区与正文区分，白字对比度达标 |
| 不做进站弹窗 | 业务 + 体验 | 采购反感；转化在证据之后 |
