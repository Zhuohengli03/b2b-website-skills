# 参考 · 素材分级与 AI 补全

> 设计出方向单前读，第 0 步清点素材时也读。这一份管**所有图**，不只是载体图。

## 顺序（这一份的全部内容就是这一条）

**错的顺序**：清点素材 → 素材不够 → 降级风格 → 出设计。
这是前 AI 时代的做法。它让素材反过来决定设计，结果是每家素材不足的公司都长得一样。

**对的顺序**：

1. 按公司和产品定方向（三步推导，见 `产品载体与场景段.md`）
2. 列出这个方向**需要哪些图**、每张在页面上干什么
3. 逐张判 L1–L4
4. AI 能补的补掉
5. 补不了的那几张，**只降那几张所在的那一段**

**降级是按图降，不是按整站降。** 一张图不够不该拖垮整个风格方向——这是旧规则最大的问题。

## 位置表：证据位 vs 呈现位

AI 能做到哪一步，取决于这个位置是证据还是呈现，**不取决于素材有多缺**。

| 位置 | 性质 | AI 可以 | AI 不可以 |
|---|---|---|---|
| 产品位（载体图、产品页主图） | **证据** | 去背、去杂物、去水印、拉直、调色、降噪、适度超分；描摹重制成线稿 / CAD 并标明是示意图 | **生成一个不存在的产品** |
| 车间 / 产线 / 设备 | **证据** | 同上，修真图 | 生成车间 |
| 证书 / 资质 | **证据** | 扫描件去斜、去阴影、提亮 | 任何内容改动 |
| 团队 / 人 | **证据** | 基本不动 | 生成人 |
| 示意图 / 结构图 / 爆炸图 / 工艺流程 | 呈现 | **放手生成**，它本来就是画的 | — |
| 氛围位 / 区块背景 / 纹理 / 装饰 | 呈现 | 生成 | 冒充实拍，或进 Our factory / Our products 语境 |
| 应用场景（产品装在什么设备上） | 半证据 | 生成，但必须读起来像插画——等距、线稿、半透明剖视 | 拍照写实的假现场 |

一句话：**证据位的像素必须来自真实拍摄，AI 只能修不能造；呈现位随便。**

### 这条线几乎不花设计感

设计感住在**呈现位**——版式、动效、插画、背景、字体、留白、节奏。证据位只要真，不需要美。

把两者分开，反而能在呈现位放开手：正因为证据位老老实实是真照片，呈现位那些生成的爆炸图、等距场景、纹理背景才不会让整个站显得可疑。**两边混着来才是最差的**，看的人分不清哪张是真的，于是哪张都不信。

## 一条硬线：不许 AI 生成产品本体

给紧固件生成一颗螺丝，螺距、头型、槽型、倒角、垫片配合全是错的。**读者是结构工程师**，他每天看这个。

而且这跟你自己看同行网站时一眼就能挑出的毛病是同一件事——「首页轮播那几张是图库图，有一张里能看到别的牌子的纸箱」。被采购抓到一次，这个站在他那里就废了。

**修真图不在这条线内。** 去背、去杂物、拉直、调色、降噪、适度超分——产品本体的像素来自真实拍摄，那是修图。超分有个限度：**能补锐度，不能补出原图里没有的螺纹**。补出来了就越线。

## 四级阶梯（所有图通用）

| 级 | 手上有什么 | 怎么做 | 出来是什么 |
|---|---|---|---|
| **L1** | 合格原图 | 直接用 | 照片 |
| **L2** | 有原图，但背景乱 / 有杂物 / 偏色 / 歪 / 带水印 / 尺寸差一点 | **AI 修**，主体像素不动 | 照片 |
| **L3** | 只有小图糊图，或这个东西拍不出效果（原料、粉末、液体、内部结构、工艺过程） | **重制成 CAD / 等距线稿 / 示意图**，标明是示意 | 插画 |
| **L4** | 什么都没有 | 按拍摄卡你自己拍 → 回到 L2；拍不到 → 这一段降级 | — |

**L2 是绝大多数项目的落点。** 工厂手里几乎都有图，问题从来是背景乱、有手、有水印、歪着拍、微信压缩过，不是没有。这些十分钟解决。

### 各位置常见落点

| 位置 | 典型情况 | 通常落在 |
|---|---|---|
| 载体图 | 有产品照但背景乱 | L2 |
| 产品页主图 | 几十上百个型号，拍全不现实 | L2 批量去背 + 统一底色与投影 |
| 车间 / 产线 | 老板手机随手拍，歪、暗、有杂物 | L2 拉直、去杂物、提亮、统一色温 |
| 证书 | 手机翻拍有阴影和梯形变形 | L2 只做去斜提亮，**内容一个像素不动** |
| 工艺流程 / 爆炸图 / 剖视 | 没有现成的，也拍不出来 | L3 生成 |
| 应用场景 | 你说不清装在哪 | L3 等距线稿，不要写实假现场 |
| 氛围位 / 区块背景 | — | 生成，加遮罩，不进 Our factory 语境 |
| 团队 | 不愿意露脸 | 不放人。用真拍的工位、手部特写，或者这一块直接不做 |

## 什么时候才真的降级

三条**同时**成立才降级：

1. 这是证据位
2. 没有可修的原图（L2 走不通）
3. 重制成示意图也不成立（L3 走不通——形态本身说不清，或重制后失真到会误导采购）

**降级只影响这一张所在的那一段，不改整站风格方向。**

## 风格禁令收窄

旧规则是「没有任何图 → 禁止极简、摄影驱动、暗色高级科技」。那是按 L4 一刀切写的，现在只保留一条：

**只有「摄影驱动」仍然禁止**——它整站靠证据位的真实照片撑，AI 补不了。

极简和暗色科技主要吃版式、留白、字体和呈现位的插画与背景，这些 AI 能供，不必禁。判断依据回到位置表：**这个风格要的图，落在证据位还是呈现位。**

## 记录与验收

`设计决策说明.md` 里**逐张**写清：落在哪一级、AI 具体做了什么（去背 / 去杂物 / 超分 / 重制 / 生成）。

QA 核的不是好不好看，是**有没有哪张证据位的图是造出来的**——出现无来源的生成图记 P0。

## 上线前最后一问

站上证据位的每一张，你自己看一眼要能说出「对，这是我们的东西」。**你认不出来的，就是造的。**
