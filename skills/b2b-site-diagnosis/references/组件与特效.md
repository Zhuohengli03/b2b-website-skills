# 参考 · 组件与特效

## 怎么读这一份

内容分三层，权重完全不同，读的时候先分清自己在看哪一层。

**必须满足**——违反了会丢询盘、丢可信度，或者在可访问性与许可上出事。这层不可协商，方案里不写理由也要照做。

**明确禁止**——已知会出事的具体做法。这层只说不能干什么，不说该干什么。

**参考形态**——**这是走通过的路，不是清单**。用里面的形态不必写理由；想走别的路完全可以，条件是在「设计决策说明」里写清它怎么满足前两层。设计的自由用归因来换，不用许可来换。

所以这份文件不是让你照抄的。前两层照抄，第三层是弹药库。

**反同质化**：比较对象是研究简报里目标市场的同行站，和 AI 建站的默认产出——采购看完这一页能不能把这家和同行区分开。**不是和别的站比**：别家公司用了什么形态跟你们公司无关，agent 不读别的项目文件夹，也不把「别处用过」当成避开的理由。同一种形态如果对你们公司是四项输入指向的最优解，就用，哪怕它常见。

**技术栈是硬前提**：WordPress 项目只能用 WordPress 区块与轻量 JS 库那两类，不要给 WordPress 项目指定 React 组件库。组件库名、JS 库名、许可状态一律以这份为准，不凭印象写。

## 询盘表单细则

询盘表单是整站唯一的转化出口，上表那一行不够用，这里展开。分层同上：必须满足照做，明确禁止不碰，参考形态可换但写归因（参考 coreyhaines31/marketingskills 的 cro/form）。

**必须满足**

| 条目 | 要求 | 归因 |
|---|---|---|
| 字段顺序 | 由易到敏感：姓名、邮箱 → 公司、需求描述 → 电话；型号从产品页带入放最前且已填好 | 体验：先投入低成本信息，填到后面放弃的成本就高了；敏感项放前面会在第一格流失 |
| 电话 | 选填；字段旁一句说明为什么要（例「仅用于报价后确认规格，不会电话推销」） | 业务：采购最怕被电话骚扰，不说明就空着或填假号 |
| 标签 | 每个字段有常驻 `<label>`，在输入框上方或旁边 | 可访问性与体验：填到一半 placeholder 消失，填表的采购忘了这格要填什么 |
| 报错 | 报错后保留所有已填内容；焦点自动落到第一个出错字段；错误文字紧邻该字段并用 `aria-describedby` 关联 | 体验：清空重填是弃单的主要原因之一 |
| 承诺句 | 表单旁一句响应时限 + 一句隐私说明（例「工作日 24 小时内回复；你的邮箱只用于回复这次询盘」）；时限用文案稿里你确认过的那个数，不现编 | 业务：采购在决定提交前要知道多久有人理、信息会不会被卖 |
| 字段级流失事件 | 每个字段的 focus / 填写 / 放弃打事件，能看出在哪一格流失 | 业务：没有这个就只知道「表单转化低」，不知道是哪一项拦住了人 |
| 蜜罐 | 隐藏字段，非空即丢，实现规则见 `b2b-frontend-dev/SKILL.md` 第 5 步 | 技术：不装 reCAPTCHA 也能挡掉多数机器人，且不加摩擦 |
| 提交按钮文案 | 写动作结果：Request a Quote / Get Pricing / Send Inquiry；全站同一句 | 业务：按钮说的是「按下去会得到什么」，不是「把表交上去」 |

**明确禁止**

- 只用 placeholder 当标签；标签只在聚焦时才出现。
- 按钮文案写 Submit / Send / 提交。
- 报错清空表单，或只在顶部给一句「有错误」。
- 一进页面就必填电话、国家下拉列 200 项、让采购选「预算范围」。
- 提交成功只弹一句「Thanks」不跳 thank-you 页（thank-you 页是转化事件与下一步引导的落点，归后端配）。

**参考形态**

- 5–7 个字段：姓名、邮箱、公司、国家（可选、自动按 IP 预填）、产品 / 型号（预填）、需求描述、电话（选填带说明）。
- 承诺句放在提交按钮正下方 13–14px 灰字；隐私说明带链接到 Privacy Policy。
- 电话字段用 `type="tel"` + 国家区号前缀；需求描述框默认 3–4 行，placeholder 给一个示例而不是说明（例「M8×40 DIN 933 8.8 级，月需 50k 件」）。

## 导航下拉的形态选型

主驱动是两件事：**一级品类有几个**，以及**产品是靠看还是靠参数选的**。下面全部属于参考层。

| 形态 | 什么时候顺手 |
|---|---|
| 不做下拉，直接跳分类页 | 一级 ≤3，或 SKU 少；最快，权重集中在分类页 |
| 单列文字下拉 | 一级 ≤3 大类，每类 5–10 项 |
| 多列文字分组 | 4–8 大类，参数型采购（紧固件、材料、化工） |
| 图标 + 文字 | 按应用或行业分类时，图标表达「行业」比缩略图准且轻 |
| 文字列表 + 右侧一张主视觉 | 想要品牌感但产品图不够多，全站只这一张图 |
| 缩略图卡片网格 | 外观差异大、靠看着选的品类：家具、灯具、包装、消费品 |
| 左右双层，左侧大类悬停切右侧 | 一级 >8 大类的贸易公司、目录站 |
| 下拉里放多维检索入口 | 同批 SKU 有多个检索维度（面料按成分 / 克重 / 幅宽） |

缩略图这一项要特别注意：紧固件、轴承、化工原料桶、线缆这类产品，缩到 80px 之后几张图长得一样，缩略图不传递信息，只增加请求和模板味。**缩到 80px 还能互相区分才用。**

## 按风格流派的样式倾向

这张表是参考层。它给的是“这个风格通常长这样”，不是“必须这样”——同一个风格做出两种气质完全正常，前提是四个参数在全站内部自洽。

| 风格 | 圆角 | 边框 / 阴影 | 悬停 | 按钮形态 |
|---|---|---|---|---|
| 国际企业 / 瑞士网格 | 2–4px | 1px 浅灰边框，无阴影 | 边框变深或背景浅灰 | 实心矩形 + 描边矩形 |
| 工业硬核 | 0–2px | 无边框，深底分区，强调色细线 | 强调色下划线出现 | 实心强调色、大写字母、字距 0.05em |
| 极简北欧 | 0–4px | 无边框无阴影，靠留白分区 | 仅文字变色 | 描边或文字按钮为主 |
| 摄影驱动 / 编辑 | 0 | 无 | 图片轻微放大 1.02 | 文字 + 下划线 |
| 科技渐变 / SaaS | 8–12px | 1px 半透明边框 + 柔和阴影，玻璃拟态导航 | 上移 2px + 阴影加深 | 渐变实心 + 描边 |
| 暗色高级科技 | 6–8px | 1px 深灰边框，无阴影 | 边框变亮 | 白底深字主按钮 |
| 奢华 | 0 | 细线 1px 金 / 黑 | 慢速（300ms）变色 | 描边细线、大写小字距 |
| 自然环保 | 12–16px | 无边框，纸张质感底 | 轻微上移 | 圆角实心，大地色 |
| 活力多彩 | 16–24px 或全圆 | 粗边框或彩色阴影 | 弹性放大 1.04 | 全圆实心 |

导航也按这张表分档：工业硬核的导航该是深底加强调色细线、字距略放宽；极简北欧该是无边框靠留白分区、更高更空；暗色高级科技该是深底、悬停时边框变亮。三种不该长成同一条白色横条。

## 用量预算（必须满足）

一个页面同时存在的动效类型不超过三种；全站钉点最多一处；脉冲 / 呼吸类动画最多一处（热点或 WhatsApp 浮标二选一）；自动播放只允许视频首屏和跑马灯。所有动效尊重 `prefers-reduced-motion`，动效脚本总量 100KB 以内（GSAP 核心 + ScrollTrigger 约 70KB，AOS 约 15KB）。

## 许可与合规（必须满足）

shadcn/ui、Radix、Flowbite 核心、Preline、DaisyUI、Swiper、Splide、GSAP（2024 年起全部免费）、Lucide 均为 MIT 或同类许可可商用；Tailwind UI、Flowbite Pro、Aceternity Pro 为付费，按项目授权，方案里注明；Uiverse 和 21st.dev 的社区组件许可各异，用前看作者标注；合作买家的 logo、字体、图标库的商用许可同样写进 `交付清单.md`（资产清单，留档给公司）。

## 动效强度分级（参考形态）

**先读 `b2b-ui-designer/references/产品载体与场景段.md` 再选这一节的条目。** 那一份决定这个项目有没有场景段、载体是哪件实物；这一节只决定选定之后每种动效的强度、时长和边界。顺序反了就会变成「给静态页面加一圈入场动画」。

按素材决定用哪一档强度，不要按「好不好看」决定。**通用的硬规则**：任何动效都要包在 `@media (prefers-reduced-motion: reduce)` 里做降级；首屏内容不许靠动效才出现（爬虫和截图都拿不到）；一个页面里同类动效只用一种。

默认「轻」，产品与信任区可以到「中」。

|---|---|---|---|---|---|---|
| Hover Micro-interaction | Subtle | hover | 150-200ms | power1.out | Don't animate layout-affecting props (width/height/margin) on hover | Runs on transform/opacity only so it stays on the compositor thread |
| Hover Micro-interaction | Standard | hover | 200-300ms | power2.out | Don't leave the hover state stuck if the pointer leaves fast; always attach the reverse tween | quickTo() avoids GC churn on lists with 20+ hoverable cards |

| Scroll Reveal | Subtle | scroll (viewport enter) | 300-400ms | power1.out | Don't reveal below-the-fold content needed for SEO/crawlers as invisible-by-default without a no-JS fallback | toggleActions 'play none none reverse' avoids re-triggering on every scroll direction chan |
