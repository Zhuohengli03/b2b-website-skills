# 参考 · 客户速查与定稿自查

两个用途：分型拿不准时查前两张表，方案定稿前和审 AI 生成页面时查第三张表。

## 产品性质对照（分型维度 B）

| 产品性质 | 例子 | 页面重心 | 对技术的要求 |
|---|---|---|---|
| 标准工业品 / 零部件 | 紧固件、轴承、线缆、阀门 | 参数表、规格筛选、材质与公差、批量报价 | 可筛选目录、参数表、快速询盘；动效要克制 |
| 设备 / 机械 / 大件 | 注塑机、包装机、工程机械、新能源设备 | 多角度实拍、工作场景视频、规格、可选配件、安装售后 | 视频 hero、热点标注图、360 或 3D 查看器（预算够时） |
| 定制加工 / OEM·ODM | 五金加工、注塑、包装盒、服装代工 | 加工能力、流程图（需求→打样→量产→交付）、案例、打样周期 | 流程可视化、案例画廊、前后对比 |
| 材料 / 化工 / 面料 | 面料、涂料、原料、复合材料 | 成分、克重、规格、应用领域、色卡、样品申请 | 色卡/样品交互、应用场景切换、数据表 |
| 消费品（B2B 分销） | 家居、灯具、户外用品、小家电 | 产品美感、系列、目录下载、分销政策 | 摄影驱动、系列画廊、目录 PDF |
| 服务 | 物流、验货、咨询 | 流程、案例、报价方式 | 流程步骤动画、案例卡片、表单 |
| 软件 | SaaS、APP、嵌入式系统 | 功能、截图、定价、文档 | 产品界面演示、交互式功能展示、定价表 |

## AI 建站的惯性毛病自查

审页面和方案定稿前对照，逐条排查。CTA 节律的规则在 SKILL.md 正文里，这里是其余各条。

| 毛病 | 表现 | 怎么改 |
|---|---|---|
| 区块节奏千篇一律 | 每个区块都是“标题 + 一句话 + 三张等宽卡片”，从头到尾同一个节奏 | 交替使用不同版式：大图左右图文、参数表、时间轴、Bento、全幅视频、案例走廊，连续两个区块不能同构 |
| 空洞形容词 | “专业、优质、高效、一站式、值得信赖”，没有一个可验证的名词 | 每个形容词换成数字或事实：50,000㎡、200 台 CNC、IATF 16949、15 天交期 |
| 图标堆砌 | 用线性图标代替真实照片，六个图标六个优点 | 图标只用于流程步骤和导航；优势区必须用车间、产品、证书的实拍 |
| 编造的数字与客户 | “服务 1000+ 客户”“合作世界 500 强”但没有依据 | 宁可不放，也不放客户拿不出证据的数字；客户 logo 要有授权 |
| 内容重复 | 首页、About、Solutions 三处讲同样的公司简介 | 每页只回答一个问题：首页“你做什么给谁做”，About“你靠不靠谱”，Solutions“我的行业你懂不懂” |
| 假 FAQ | 问题是编的，答案是套话 | FAQ 只写采购真会问的：起订量、交期、付款方式、样品政策、能否 OEM |
| 装饰性动效 | 每个区块都渐入、每张卡片都悬停放大、标题逐字出现 | 按第四步的规则，动效只留能帮人看懂内容的那几处 |
| 页脚塞满 | 页脚放了四栏几十个链接，加地图加二维码加订阅 | 页脚只放联系方式、主要分类、证书、合规链接；对国内客户加微信二维码，对海外客户换成 WhatsApp 和 LinkedIn |
| 中英混排的语气 | 英文页面是中文思维直译，“Welcome to visit our factory” | 用采购的英语写：动词开头、短句、具体名词 |
| 字体没有行业感 | 整站一种 Inter，标题全大写宽字距到处用，深色底上细体，参数数字不等宽 | 按第五步字体设计一节重定：风格定字族、背景定字重、页面定层级、产品定点缀 |

### 版式级 AI 味

上一张表审的是内容与结构，这一张审版式。单条出现不致命，**同时命中三条以上，采购一眼就是「AI 生成的模板站」**，方案定稿与设计交稿前都要过一遍（清单参考 anthropics/skills 的 frontend-design 与 plugin87/ux-ui-agent-skills）。

| 毛病 | 表现 | 怎么改 |
|---|---|---|
| 全大写小字 eyebrow | 每个标题上方都有一行 OUR SERVICES / WHY CHOOSE US 式的全大写小字 | 全站最多用在一处（通常是首屏），其余删掉；要分组标签时用正常大小写的短语 |
| 中点串 | 「A · B · C」用中点把三个词串成一行当副标题或标签 | 改成一句带动词的话，或拆成列表；三个名词并列说明不了任何事 |
| 按钮尾巴统一「→」 | 所有按钮文字后面都带箭头 | 箭头只留给「去另一页」的链接型按钮；主按钮写动词短句（Get a Quote、Request Samples），不带符号 |
| 非顺序内容编号 | 优势、特点这类没有先后的内容编成 01 / 02 / 03 | 编号只用于真有顺序的流程（询盘 → 报价 → 样品 → 量产）；并列内容去编号，靠标题本身区分 |
| 三张等权卡片一排 | 一屏三张等宽等高的卡片，各配一个图标 | 按重要性分主次：一大两小、或一张大图 + 文字列表；或换成参数表 / 时间轴（见上表「区块节奏」） |
| 左文右图连排 | 左文右图、右文左图交替三屏以上 | 最多连排两屏，第三屏必须换版式（全幅图、Bento、表格） |
| 全部居中 | 标题、正文、按钮全部居中对齐 | 正文与列表左对齐；居中只留给首屏标题与页尾 CTA 这类单句区块 |
| 每个盒子都投影 | 卡片、图片、按钮全带阴影 | 阴影只用于悬浮层（下拉、弹层）；卡片用 1px 边框或底色差区分，工业 / 企业风无阴影或极淡 |
| emoji 当图标 | 用 ✅ 🚀 ⚙️ 当列表或优势图标 | 换成同一套线性图标，或直接去掉图标只留文字 |
| 默认配色 | 米白 + 陶土、近黑 + 荧光绿、紫蓝渐变这类 AI 工具的默认调 | 主色从客户 logo 吸，强调色一个；每个色要能说出「取自哪里」 |
| 营销空词 | seamless / elevate / unlock / empower / cutting-edge | 每个换成可验证的名词或数字（见上表「空洞形容词」），回流文案 |
| em dash 对比标题 | 标题靠「—」制造对比或转折（Built for Scale — Designed for You） | 一个标题只说一件事，破折号拆成两句或删掉后半句 |

归因：业务——这些版式是 AI 工具的默认输出，海外采购近两年见得太多，识别为模板站就直接怀疑公司规模；视觉——每一条都是「用符号替代层级」，去掉之后反而逼出真正的层级。
