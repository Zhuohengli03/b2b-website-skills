# 参考 · 展示技术清单

出第四节「展示技术清单」前读这一份。**常规展示技术只从这张表里选，表里没有的不写进方案。**记不清某项的适用条件就回来读，不要凭名字推断。

**一个例外：产品载体场景段。** 它的做法从你们公司自己的产品推导，不在本表内（见 `b2b-ui-designer/references/产品载体与场景段.md`）。技术清单里只登记两件事：**有 / 无**、**放哪一段**；具体怎么动由设计在 G2 方向单里定。

每一行的「不适合」列和「实现与成本」列跟「适合」列一样重要——多数误判是只看了适合列。

下表是市面上主流的展示技术，按“用在哪、适合谁、别用在哪”整理。实现方式给到开发能直接落地的程度。

| 技术 | 效果描述 | 适合的站型 / 公司 | 不适合 | 实现与成本 |
|---|---|---|---|---|
| 滚动钉点叙事（Scroll pinning / Pin sections） | 下滑时一块区域固定住，旁边或内部的内容随滚动分步切换，常用于“三步流程”或“一个产品的四个卖点” | 设备 / 机械 / 定制加工的流程页；品牌站的产品故事；解决方案站的“问题→方案” | 参数密集的标准件目录；移动端优先的市场（钉点在手机上容易失控） | GSAP ScrollTrigger pin，或 CSS `position: sticky` + Intersection Observer；中等成本 |
| 滚动渐入与错落出现（Scroll reveal / stagger） | 元素进入视口时淡入、上移，多个卡片依次出现 | 几乎所有站型的通用基础动效，安全牌 | 无 | CSS + Intersection Observer 或 GSAP；低成本，默认都可以加 |
| 图片序列擦洗（Scroll scrub / image sequence） | 滚动驱动一组帧图或视频进度，产品随滚动旋转拆解（苹果式） | 高客单设备、消费电子品牌、有 3D 建模或高质量拍摄的产品 | 没有专业素材的工厂；网络差的市场 | 需要 60–200 帧渲染图或 WebM 视频，GSAP scrub；高成本，先确认素材 |
| 视差（Parallax） | 背景与前景以不同速度移动，制造纵深 | 品牌站、工厂实景 hero、About 页的车间大图 | 大量使用，尤其在产品目录页 | CSS transform + 滚动监听；低成本，但要限制在 1–2 处 |
| 横向滚动区块（Horizontal scroll section） | 垂直滚动时区块内容横向平移，展示时间轴、系列或案例流 | 品牌站的系列展示、公司发展时间轴、案例走廊 | 询盘站主流程；移动端效果差，需要降级为普通轮播 | GSAP ScrollTrigger + pin；中等成本 |
| 遮罩穿透 / 光标透视（Mask reveal / cursor spotlight，双层图上层被光标“擦开”） | 两张同尺寸图叠放，鼠标经过处上层被圆形遮罩挖开露出下层：产品外观 ↔ 内部结构、白天 ↔ 夜景、粗坯 ↔ 成品 | 有“表里对比”卖点的产品：机械内部结构、LED 灯亮灭效果、涂层前后、面料正反面；品牌站的氛围 hero | 没有成对素材时硬凑；触屏设备（无悬停，需要降级为拖动或自动动画） | CSS `mask-image` 跟随鼠标坐标，或 canvas；低到中成本，关键是成对素材 |
| 前后对比滑块（Before / After slider） | 拖动分割线比较两张图 | 表面处理、涂装、翻新、清洁设备、定制前后、软件界面新旧 | 没有明确前后差异的产品 | 原生 `input[type=range]` + clip-path；低成本，触屏友好 |
| 热点标注图（Image hotspots） | 产品大图上有若干可点的圆点，点击弹出部件说明 | 设备 / 机械 / 复杂组件、家具结构、包装结构 | 单一简单产品 | HTML 定位 + 弹层；低成本，对 SEO 友好 |
| 360° 旋转与 3D 查看器（360 spin / Three.js / model-viewer） | 拖动旋转产品，可缩放，可展开部件 | 高客单设备、精密零件、家具、消费电子；有 3D 模型或愿意做 3D 建模的公司 | 预算有限的工厂；参数比外形重要的标准件；文件大于 3MB 的模型 | 360 用 36–72 张序列图最省；3D 用 `<model-viewer>` 加 glTF；中到高成本 |
| WebGL 沉浸式场景 / 着色器（Shader、液态、粒子背景） | 首屏流体、粒子、扭曲文字等图形效果 | 创意机构、时尚、软件与科技品牌的 hero | 几乎所有工厂和贸易询盘站；网络差的市场；对 SEO 有依赖的页面 | Three.js / Unicorn Studio；高成本、800KB–2MB 的负担，B2B 默认不用 |
| 视频首屏（Video hero / background video） | 首屏自动播放的静音车间或产品视频 | 工厂（最能证明“真有厂”）、设备演示、品牌氛围 | 没有能看的视频；东南亚非洲市场需要提供静态图降级 | 压缩到 10 秒内、2–4MB 以内的 MP4/WebM，带 poster 图；低成本，但素材质量决定一切 |
| 数字滚动计数器（Counter） | 数字从 0 滚到“20 年 / 50,000㎡ / 200 台 CNC” | 询盘站的产能数字、About 页、服务商的成绩单 | 数字很小或编不出来的公司（宁可不放） | 数十行 JS；低成本，询盘站强烈推荐 |
| Logo 跑马灯（Marquee） | 合作买家或认证 logo 横向无限滚动 | 有真实的合作买家 logo 或认证的任何 B2B 站 | 没有授权用买家 logo 时（改为“服务过 30+ 国家”文字） | CSS animation；低成本 |
| 动态文字（Kinetic / split text） | 标题按字或按词逐个出现、滚动变色 | 品牌站、软件站的 hero 标题；一个页面最多用一次 | 正文和参数；SEO 关键标题要保证 DOM 里有完整文字 | GSAP SplitText 或 SplitType；低成本 |
| Bento 网格（Bento grid） | 大小不一的卡片拼成信息板，一屏展示多种信息 | 软件站的功能总览；询盘站的“能力总览”（产能、证书、交期、OEM 各一格）；About 页 | 长文叙事 | CSS Grid；低成本，2024 年起已成通用布局 |
| 悬停卡片与 3D 倾斜（Hover card / tilt） | 鼠标经过卡片放大、抬升、轻微倾斜 | 产品分类卡、案例卡、服务卡 | 过度倾斜显得廉价 | CSS transform；低成本，幅度控制在 2–4 度 |
| 可筛选产品目录（Filterable catalog） | 按材质 / 尺寸 / 用途 / 行业筛选，实时刷新 | 标准件、材料、SKU 多的贸易公司 | SKU 少于 20 个的公司 | WordPress 分类法 + Ajax 筛选，或前端过滤；中等成本，询盘站的核心功能 |
| 参数表切换（Tabs / accordion 规格表） | 产品页用标签页组织“参数 / 应用 / 包装 / 下载” | 所有工业品、材料 | 无 | 原生 HTML；低成本，必备 |
| 粘性询盘条 / 浮动 WhatsApp | 滚动时页面底部或侧边始终有“Get a Quote”和 WhatsApp | 所有询盘站，尤其中东、拉美、东南亚市场 | 无 | 数行 CSS；低成本，必备 |
| 粘性侧栏目录（Sticky sidebar） | 长页面左侧固定目录或产品分类，右侧滚动 | 解决方案站、文档页、长参数页 | 页面短的站 | CSS sticky；低成本 |
| 巨型下拉菜单（Mega menu） | 导航悬停展开带图的分类面板 | 品类多于 3 大类的工厂和贸易公司 | 品类少的公司（普通下拉即可） | 主题自带或自定义；低成本 |
| 交互式地图（Global presence map） | 世界地图上标出买家分布、仓库、办公室 | 贸易公司、物流服务商、出口到 30 国以上的工厂 | 买家集中在一两个国家时 | SVG 地图 + 标点；低成本 |
| 页面过渡（Page transitions） | 页面之间用遮罩或淡入淡出衔接 | 品牌站、创意站 | 询盘站（增加等待感，影响可抓取性判断） | barba.js 或 View Transitions API；中等成本 |
| Lottie / Rive 微动画 | 轻量矢量动画：流程图标动起来、按钮反馈 | 服务商的流程页、软件站的功能说明 | 用来替代真实照片 | Lottie / Rive；低到中成本 |
| 自定义光标（Custom cursor） | 光标变成圆点或跟随指示 | 创意机构、品牌站 | 所有 B2B 询盘站（采购会困惑） | CSS + JS；低成本但默认不用 |
| 玻璃拟态（Glassmorphism） | 半透明毛玻璃导航栏、卡片 | 软件站、科技硬件品牌的导航和弹窗 | 大面积使用（性能和可读性都差） | CSS backdrop-filter；低成本，限用于导航与弹层 |
| 暗色模式（Dark mode / 暗色主题） | 整站或首屏用深色底 | 科技、精密设备、LED 灯具、高端消费电子、汽车配件 | 食品、母婴、家居布艺、以“干净可信”为核心的化工原料 | 设计层面决策；成本在于所有图片要在深色底上重新审 |
