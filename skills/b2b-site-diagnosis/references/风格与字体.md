# 参考 · 风格流派与字体

第五节定风格与字体前读这一份。内容分两种权重，先分清在看哪一种。

**必须满足**（不可协商，散在下面各节，这里先列全）：

- 深色底上正文字重加一档、不用 300 以下细体、纯白改 #f5f5f5；正文与背景对比度按 WCAG 至少 4.5:1。
- 图片或视频上叠字必须加 30–50% 遮罩或渐变，字重 600 以上，字号不小于 32px。
- 参数表数字启用 `tabular-nums`；表单输入框在手机上不小于 16px（低于会触发缩放）。
- 每页只有一个 H1。
- 字体自托管 woff2，总量 300KB 以内，`font-display: swap` 并配宽度接近的回退栈。
- 多语言页面用覆盖该语种的字体（阿拉伯语用 Noto Sans Arabic / Cairo 并做 RTL 镜像；泰语越南语用对应 Noto 变体）。用只覆盖拉丁字母的字体，整页会回退成系统字体、气质全崩。
- 一张实拍都没有时，主风格只能在国际企业风、工业硬核风、Bento 排版型三者中选（这条在 SKILL.md 正文，此处只作提醒）。

**参考层**——下面所有的风格流派表、字体气质表、按风格的字体配对、字号阶梯的具体数值，**都是走通过的路，不是清单**。用它们不必写理由；想用表外的字体或另一种配法完全可以，条件是在「风格与字体方向」里写清它怎么满足上面那几条，以及它为什么更贴你们公司。同一个风格流派做出两种气质是正常的，不是错误。

反过来说：如果不管输入是什么、字体方案都是 Inter 配 Inter，那不是这张表的错，是没在选。

风格的匹配逻辑七条在 SKILL.md 正文里，不在这里——这里只有可选项本身。

## 风格流派

**没有默认风格。** 风格由四项输入决定：公司类型（工厂 / 贸易 / 品牌 / 服务 / 软件）、产品性质（硬核工业品 / 标准件 / 偏软消费向 / 技术型）、目标市场的审美基线（研究简报给）、素材条件（有没有够好的实拍）。四项对上哪一行就选哪一行，对不上再看第二候选，方案里写清四项各指向哪里。

两条禁令：**不因为某个风格常见就避开它**——常见是因为它对那类公司有效，避开等于为了不同而不同；**不因为别家用过就避开它**——别家公司的选型与你们公司无关，agent 也不该去看。同质化的比较对象是研究简报里目标市场的同行站和 AI 默认模板，判断依据是「采购能不能一眼把你们和同行区分开」，不是「和别的站像不像」。


风格由色彩体系、字体气质、版式密度、图片处理方式四样东西共同决定。下表按“这套风格在传递什么信号”来分，因为买家看到网站时，读到的是信号，不是术语。

| 风格流派 | 传递的信号 | 视觉特征 | 适合的公司 / 产品 | 不适合 | 参考类型 |
|---|---|---|---|---|---|
| 国际企业 / 瑞士网格风（Corporate clean / Swiss） | 专业、可靠、大公司 | 白底、蓝或深灰主色、无衬线字体、严格网格、大量留白、真实照片 | 零部件、材料、化工、机械等标准工业品；选型人是采购部门而非工程师；欧美市场 | 想强调设计感的消费品牌 | 西门子、博世式的工业官网 |
| 工业硬核风（Industrial / technical） | 硬实力、精密、耐用 | 深灰或黑底配一个高饱和强调色（橙、黄、青），等宽或几何字体，蓝图线条、网格纹理、大号参数数字 | 机械设备、工具、汽车配件、精密加工、新能源硬件 | 食品、纺织、母婴、需要“温和可信”的品类 | 工具品牌、工程机械厂商官网 |

| 摄影驱动 / 编辑风（Photography-led / Editorial） | 真实、有故事、有质感 | 全幅实拍、杂志式排版、衬线与无衬线搭配、大标题、图文交错 | 有一流拍摄素材的工厂（车间、工艺、人物）；食品原料、农产品、手工艺、服装代工 | 没有好图的公司；SKU 极多的目录站 | 高端食材、工艺品牌的品牌站 |
| 科技渐变 / SaaS 风（Tech gradient） | 创新、现代、软件感 | 深蓝紫底或白底配渐变光斑、玻璃拟态卡片、圆角、产品截图、Bento 网格 | 软件、SaaS、智能硬件、物联网、储能与新能源“科技属性”产品 | 传统制造业（会显得不真实）、纺织与家居 | 主流 SaaS 官网 |
| 大胆 / 粗野主义（Bold / Brutalist / Anti-grid） | 态度、年轻、反套路 | 超大字、黑白高对比、粗边框、打破网格、原始感 | 创意机构、潮流品牌、独立 SaaS、面向年轻消费者的 B2C | 几乎所有面向采购的 B2B 站 | 独立设计工作室官网 |
| 奢华 / 高端风（Luxury） | 稀缺、精致、昂贵 | 黑金或黑白、衬线字体、慢节奏动画、大量负空间、细线条 | 珠宝、高端定制、奢侈包装、高端家具、高端美妆代工的品牌站 | 走量的工业品 | 奢侈品牌官网 |
| 自然 / 环保风（Organic / Eco） | 可持续、天然、健康 | 米白、大地色、绿色系，圆润形状，纸张纹理，手写或人文无衬线 | 食品、农产品、可降解包装、竹木制品、有机纺织、宠物用品 | 精密机械、电子 | 可持续消费品牌官网 |
| 活力多彩风（Playful / Colorful） | 友好、有趣、亲和 | 明亮多色、插画、圆角、动态图标 | 玩具、文具、儿童用品、派对用品、教育产品、部分消费电子配件 | 工业与专业服务 | 玩具与文具品牌官网 |
| 暗色高级科技风（Dark premium） | 高性能、高端电子 | 黑底、产品打光图、金属质感、大号型号名、滚动擦洗动画 | 消费电子品牌、LED 与照明、电动工具、电竞外设、汽车电子 | 需要“明亮干净”的品类 | 消费电子旗舰官网 |
| 复古 / 手作风（Retro / Craft） | 传承、手工、匠人 | 复古配色、衬线、纹理、老照片 | 传统工艺、老字号、茶叶、酒类、手工皮具 | 现代工业品 | 老字号品牌官网 |

### 字体设计：按公司风格、页面、背景色、产品定

字体是风格里最容易被 AI 建站做砸的一环：要么整站 Inter 从头用到尾，要么每个区块字号都不一样。字体传递的信号和色彩一样直接——采购看到细衬线会觉得“这是卖设计的”，看到等宽数字会觉得“这是懂参数的”。定字体的顺序是：先按风格流派选字体气质 → 再按背景色调字重和字号 → 再按页面类型调层级 → 最后按产品风格做点缀。

**字体气质分类**（英文站为主，中文站另见后文）：

| 气质 | 代表字体（可免费商用） | 传递的信号 | 适合的风格 / 公司 | 不适合 |
|---|---|---|---|---|
| 几何无衬线 | Inter、Manrope、Montserrat、Poppins、Plus Jakarta Sans | 现代、中性、可靠 | 国际企业风的常用选择；工厂询盘站、贸易公司、服务商 | 想有个性的品牌站（太“通用”） |
| 人文无衬线 | Source Sans 3、Open Sans、Noto Sans、Lato、Nunito Sans | 亲和、易读、稳妥 | 正文首选；食品、纺织、家居、需要“温和可信”的品类；多语言站 | 硬核工业的标题（不够硬） |
| 工业 / 工程感 | IBM Plex Sans、Space Grotesk、Barlow、Roboto Condensed、Archivo、DIN 类 | 精密、技术、耐用 | 工业硬核风；机械、工具、汽配、精密加工、新能源 | 食品、母婴、奢华 |
| 等宽 | IBM Plex Mono、JetBrains Mono、Space Mono | 数据、型号、工程师 | 只做点缀：型号、参数标签、Counter 数字、证书编号 | 标题和正文（可读性差） |
| 现代衬线 | Playfair Display、Fraunces、Cormorant、EB Garamond、Libre Caslon | 品味、传承、高端 | 极简北欧、奢华、摄影驱动、复古手作的标题；家具、面料、食材、皮具 | 参数密集的工业品；小字号正文（屏幕上发虚） |
| 圆体 | Nunito、Quicksand、Varela Round | 友好、安全、童趣 | 活力多彩风；玩具、儿童用品、宠物、教育 | 所有面向采购的工业站 |
| 窄体 / 展示体 | Bebas Neue、Oswald、Anton、Barlow Condensed | 力量、冲击、大数字 | 工业硬核风的大号数字和 hero 标题；工具、机械、电动工具 | 正文；一页超过两处 |

**按风格流派配字体**（标题 / 正文 / 点缀，每站最多两种字族，等宽算第三种只能点缀）：

| 风格流派 | 标题 | 正文 | 点缀 | 说明 |
|---|---|---|---|---|
| 国际企业 / 瑞士网格 | Inter 或 Manrope（600–700） | 同字族 400 | 无，或 IBM Plex Mono 做型号 | 标题正文同一字族最稳，靠字重和字号拉层级 |
| 工业硬核 | Space Grotesk、Barlow 或 Archivo（700） | IBM Plex Sans 或 Barlow（400） | Plex Mono 做参数与 Counter | 标题可略收紧字距（-0.02em），大数字用窄体 |
| 极简北欧 | 细字重几何体（Manrope 300–400，大字号）或细衬线（Cormorant） | Inter / Source Sans 400 | 无 | 靠字号差和留白拉层级，不靠加粗 |
| 摄影驱动 / 编辑 | 现代衬线（Playfair、Fraunces） | 人文无衬线（Source Sans 3） | 衬线斜体做图注 | 衬线只用在 32px 以上 |
| 科技渐变 / SaaS | Inter、Plus Jakarta Sans、Geist 类（600–700） | 同字族 400 | Mono 做代码或数据 | 标题可用渐变文字，一页一次 |
| 暗色高级科技 | 几何体 700，字距略放宽 | 同字族 400，字重比浅底加一档 | Mono 做型号 | 深色底细字会糊，见下面背景色规则 |
| 奢华 | 衬线（Cormorant、Playfair）配大写小字距标题 | 人文无衬线 | 无 | 全大写 + 字距 0.1–0.2em 只用于小标题 |
| 自然环保 | 人文无衬线或圆润衬线（Fraunces soft） | Nunito Sans / Source Sans | 手写体最多一处 | 忌黑体粗标题 |
| 活力多彩 | 圆体或粗几何体（Poppins 700） | Nunito | 无 | 字号可以偏大 |
| 复古手作 | 老式衬线（Libre Caslon、EB Garamond）或 slab（Zilla Slab） | Source Sans | 手写体做签名 | 纹理不要加在正文上 |

**按背景色调整**：

- 浅底（白 / 浅灰）：正文 400，16–18px，正文色用 #1a1a1a 到 #333 而不是纯黑；标题 600–700。
- 深底（深蓝 / 黑 / 深灰）：正文字重加一档（400 → 500），字号加 1–2px，行高加 0.1，字距略放宽（+0.01em）；不用 300 以下的细体；纯白改为 #f5f5f5 减少眩光；对比度按 WCAG 至少 4.5:1。
- 品牌色底（深蓝、橙、绿的大色块 CTA 区）：只用白字或接近白的字，不放彩色字；标题 700；正文控制在两行以内，长文案放回浅底。
- 图片上叠字（视频首屏、车间大图）：必须加 30–50% 深色遮罩或底部渐变，字重 600 以上，字号不小于 32px；图片亮部落在文字区域时换图或换位置。
- 玻璃拟态 / 半透明卡片上：字重加一档，避免细体，卡片内文字不超过三行。

**按页面类型调整**：

| 页面 / 区块 | 字体处理 | 原因 |
|---|---|---|
| 首屏 hero | 标题 48–64px（桌面）/ 32–40px（手机），字重 700，一行最多 8–10 个英文词；副标题 18–20px 400 | 5 秒内要读完定位句 |
| 产品目录 / 卡片 | 产品名 18–20px 600，型号用 Mono 或 tabular 数字，参数摘要 14px | 扫读效率优先 |
| 产品详情 / 参数表 | 表格 14–15px，数字启用 `font-variant-numeric: tabular-nums`，单位与数值分开对齐，表头 600 | 采购会逐行比参数，数字不等宽会看错 |
| About / 产能数字 | Counter 数字 48–72px 700 用窄体或几何体，标签 14px 大写 + 字距 0.08em | 数字是主角 |
| OEM 流程 / 步骤 | 步骤序号用大号 Mono 或窄体，步骤名 20px 600 | 序号本身是导航 |
| 案例 / Blog 正文 | 正文 17–18px，行高 1.7，段宽 65–75 字符，可用衬线 | 长文可读性 |
| 表单 | 标签 14px 500，输入框 16px（手机上低于 16px 会触发缩放），按钮 16px 600 | 填表不出错 |
| 页脚 | 14px 400，标题 14px 600 大写，链接色比正文淡一档 | 收束，不抢戏 |

**按产品风格做点缀**：精密机械、电子、汽配可以在型号和参数处用等宽体，强化“工程感”；家具、面料、灯具在标题处用细字重或衬线，强化“设计感”；食品、农产、手工艺在图注或引言处用衬线斜体，强化“故事感”；玩具、宠物在标题处用圆体；软件在功能名处用 Mono 做标签。点缀只在一类元素上出现，不要让衬线、圆体、等宽在同一页并存。

**字号阶梯与全站规则**：定一套阶梯全站复用，例如 14 / 16 / 18 / 24 / 32 / 48 / 64，行高正文 1.6、标题 1.1–1.2；每页只有一个 H1；字族不超过两种，字重不超过四个文件（如 400 / 500 / 600 / 700）；标题字距在大字号时收紧（-0.01 到 -0.03em），小标题大写时放宽（0.05–0.15em）；正文永远不全大写。

**中文站与多语言站**：中文标题用思源黑体 / Noto Sans SC（或系统字体栈 PingFang SC、Microsoft YaHei），字重 500–700，字号比英文同级大 1–2px，行高 1.7–1.8；中英混排时英文和数字用同一无衬线以免跳动；面向中东的阿拉伯语页面用 Noto Sans Arabic / Cairo 并做 RTL 镜像；泰语、越南语等用 Noto Sans 对应变体，不要用只覆盖拉丁字母的字体（会回退成系统字体，整页气质崩掉）。

**性能规则**：字体自托管 woff2，不直接引 Google Fonts（国内访问慢，海外也多一次 DNS）；每个字族最多 3–4 个字重文件，总量控制在 300KB 以内；`font-display: swap` 并设置与自定义字体宽度接近的回退字体栈（如 Inter 回退到 Arial/Helvetica），避免加载时排版跳动。

**字体上的 AI 惯性毛病**：整站只有 Inter 或 Poppins 一种气质，看不出行业；标题全大写加宽字距到处都是（这个手法一页只用一次）；每个区块字号阶梯不一致（同级标题一处 28px 一处 36px）；深色底上用 300 细体；参数表数字不等宽；中文站直接套英文字号和行高显得挤；字体从 Google Fonts 加载了六七个字重。审页面时把这几条和 CTA 一起数。

## 明确禁止 · 流行风格名录

你、同行或 AI 生成器最常提到的一批风格名。**这些名字出现时，答案在下面这张表里，不要现场判断。**「慎用」的必须写归因，说明为什么你们公司是例外。

| 风格名 | 结论 | 它自己写的适用场景 | 为什么对 B2B 询盘站不成立 |
|---|---|---|---|
| Neumorphism | **不用** | Health/wellness apps, meditation platforms, fitness trackers, minimal interaction UIs | 对比度天生不足，参数表和证书区会糊；采购在办公室强光下看不清 |
| Glassmorphism | **慎用** | Modern SaaS, financial dashboards, high-end corporate, lifestyle apps, modal overlays, navigation | 只可用于导航栏或弹层，且底下必须是纯色不是照片；不要用在产品卡片 |
| Claymorphism | **不用** | Educational apps, children's apps, SaaS platforms, creative tools, fun-focused, onboarding, casual games | 圆润膨胀感读起来像儿童应用，和工业品的可靠感相反 |

| Y2K Aesthetic | **不用** | Fashion brands, music platforms, Gen Z brands, nostalgia marketing, entertainment, youth-focused | 面向采购的任何页面都不适用 |
| Vaporwave | **不用** | Music platforms, gaming, creative portfolios, tech startups, entertainment, artistic projects | 同上 |
| Memphis Design | **不用** | Creative agencies, music sites, youth brands, event promotion, artistic portfolios, entertainment | 同上 |
| Gen Z Chaos / Maximalism | **不用** | Gen Z lifestyle brands, music artists, creative portfolios, viral marketing, fashion | 同上 |
| Cyberpunk UI | **不用** | Gaming platforms, tech products, crypto apps, sci-fi applications, developer tools, entertainment | 只有电竞外设和部分消费电子撑得住，B2B 询盘站一律不用 |
