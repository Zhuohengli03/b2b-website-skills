# 参考 · 对话表：第一步要收齐的信息

从 SKILL.md「第一步：把信息收齐」原样搬入。至少要拿到下面这些。拿不到的先按最合理假设推进，并在方案里标 `[待确认：X]`。

| 项目 | 为什么要 |
|---|---|
| 公司类型：工厂 / 贸易公司 / 品牌方 / 服务商 / 软件或 SaaS | 决定站的叙事主线（产能 vs 选品能力 vs 品牌 vs 案例） |
| 产品或服务是什么、主打几个品类、有没有 OEM/ODM | 决定产品页结构和技术选型 |
| 买家是谁：经销商 / 品牌方采购 / 工程承包商 / 终端消费者 / 企业用户 | B 端还是 C 端，决定站型 |
| 客单价、起订量、决策周期 | 高客单长周期 → 信任建设为主；低客单 → 转化路径为主 |
| 目标市场（欧美 / 中东 / 东南亚 / 拉美 / 非洲） | 决定语言、网络环境对动效的容忍度、审美偏好 |
| 现有素材：工厂实拍、产品图质量、视频、证书、买家案例、合作买家的 logo（放跑马灯的第三方 logo，需授权） | 素材决定风格上限，没有好图就不能选摄影驱动型风格 |
| 品牌 logo：你们公司自己的标，源文件格式与分辨率、有无矢量、有无横版竖版纯图标变体 | 有就必须用原标，这一项和上面那行的「合作买家的 logo」是两回事，不要混 |
| 旧网址（如有） | 做旧站体检，决定保留什么、推翻什么 |
| 预算、上线时间、后续谁维护 | 决定技术复杂度的上限 |
