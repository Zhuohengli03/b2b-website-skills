# 参考 · 特殊情况处理

从 SKILL.md「特殊情况处理」一节原样搬入；正文在拿不准时指到这里读。

下面这些情况在真实项目里比“资料齐全”更常见。原则是：资料少不等于不能判断，判断可以带假设；素材差不等于不能设计，风格可以降级；但永远不编造、不用网图、不冒充。

| 情况 | 怎么判断 | 怎么办 |
|---|---|---|
| 你给的资料只有一句话（“我们做紧固件，要个英文站”） | 需求单 12 项少于 5 项有答案 | 启动“最小可行诊断”：先从公开来源补——阿里国际站 / 1688 店铺、旧站、企查查 / 天眼查工商信息（成立年份、注册资本、经营范围能判断工厂还是贸易）、Google Maps 卫星图看厂房、LinkedIn 员工数、展会目录、海关数据。按“公司类型 + 产品性质”两项推默认站型（国内工厂和贸易公司默认询盘站）。方案里单开一节“假设清单”，每条写“假设 X；若不成立则改为 Y”。先出初判，不等你补资料。需要你补的问题压缩到 5 个以内（公司类型、买家是谁、主要市场、有没有实拍、有没有硬节点），记进 `_内部/待用户决定.md`，经 PM 一次问完 |
| 你的自述与公开信息矛盾 | 说是工厂但工商登记是贸易；说 20 年历史但成立 3 年；说出口 50 国但旧站只有中文 | 直接指出矛盾点。方案按可证明的版本写，矛盾点列进“待确认”和 `_内部/待用户决定.md` 由你核实。网站上只写能证明的；证明不了的换成相邻可证表述（“合作工厂经我方验厂”“出口 15+ 国家”） |
| 没有任何图 | 素材清单里车间、产品、证书三项全空 | 三件事同时做。**判断降级**：只禁止**摄影驱动**（它整站靠证据位的真实照片撑，AI 补不了）；极简、暗色高级科技、Bento 主要吃版式与呈现位，AI 能供，不再禁——判断依据见 `b2b-ui-designer/references/素材分级与AI补全.md` 的位置表。风格仍由四个输入决定，不因为缺图就固定成某三种；技术清单去掉视频首屏、遮罩穿透、图片序列、360，热点标注改成参数表。**过渡方案分三级**：一级——你自己用手机拍，给拍摄清单（车间全景 2 张、产线或设备特写 3 张、每类主推产品纯色底 3 张、证书、团队合影；横构图、白天靠窗自然光、不开滤镜、原图传输不走微信压缩）；二级——拍不出效果的产品（原料、化工、软件、服务）用示意图、结构图、CAD 渲染、界面截图、“图标 + 参数卡”替代，全站一套线稿风格，**这一级可以放手用 AI 生成，因为它本来就是画的、不冒充照片**（证据位与呈现位的分界见 `b2b-ui-designer/references/产品载体与场景段.md` 的位置表）；三级——氛围位允许用授权图库图（Unsplash / Pexels 商用许可）但只做背景与行业场景并加深色遮罩，不得出现在“Our factory”“Our products”语境，方案里标明。**写进方案**：“素材清单”一节改为“素材补拍计划”，标明哪些区块在图到位前用什么、图到位后怎么升级（组件位置不变，换图即可） |
| 只有阿里店铺的低清图或带水印图 | 图宽 < 800px、有平台水印、白底抠图粗糙 | 低清图只用于 ≤ 400px 的产品卡，不上 hero；带水印的一律不用；方案建议你先拍 10 张主推产品，其余沿用低清图过渡 |
| 只有渲染图 / 效果图，没有实拍 | 常见于家具、灯具、设备 | 渲染图可上产品位，但 About 与首页“证据区”必须是实拍或不放图（改数字与时间轴）；方案写明“渲染图给产品，实拍给信任” |
| 旧站打不开、被墙、已过期 | 访问超时、域名过期页、证书失效 | 用 Wayback Machine 看历史版本；Google `site:` 看收录残留与 URL 结构（给后端做 301 清单）；仍看不到就按无旧站处理，旧站体检一节写明原因 |
| 你提名的参考站与预算不符 | 想要苹果 / 特斯拉级效果，预算有限；参考站是品牌站，你们是工厂 | 拆参考站找你真正喜欢的 2–3 个点（多半是留白、大图、少字、单一强调色），这些都能用排版实现。方案写一张两列表：“参考站的 X → 本期用 Y 实现同样感受；参考站的 Z 需要专业摄影 / 3D / 动效预算，本期不做”。不出两套方案让你选 |
| SKU 极端 | ≤ 5 个 | 不做分类页，产品直接挂一级导航，产品页做深（应用、参数、案例、FAQ） |
| | ≥ 1000 个 | 首期 30–50 个代表产品 + 可筛选目录 + 目录 PDF 下载，其余批量导入或你在后台自加；方案写明“首期范围” |
| 行业冷门、搜索量为零或品类敏感 | 型号级产品、军民两用、医疗器械、化学品 | 站型仍按规则判断；页面按型号 / 标准号 / 应用场景组织而不是按泛品类词；技术清单加合规声明区与证书区，方案标注需要你提供的资质；不给“做不了 SEO”的结论 |
| 服务商 / 软件没有“产品图” | 本来就没有实物 | 不套工业品技术包；用流程图、界面截图、案例卡、团队实拍、Lottie 流程动画；风格按国际企业或科技渐变 |
| 公司里多个决策人意见冲突 | 老板要“大气”，外贸经理要参数，儿子要“像苹果” | 方案只给一条主线（按采购需要），把每一方的诉求落在具体区块并写明：About hero 与首屏留白给老板的“大气”，产品页与目录给外贸经理的参数；不出两套方案（agent 给一条主线，不把决策成本推回给拍板人） |
| 你不知道自己的买家是谁 / 目标市场 | 需求单里“买家类型”“主要市场”为空 | 从旧站询盘、阿里店铺的成交国家、海关数据推前三个市场；买家类型按产品性质推（标准件 → 经销商与 Tier 2；设备 → 终端工厂与工程商）；写进假设清单 |
| 你现有的资料或旧站是面向国内的 | 旧站是中文站或“阿里国际站 / 1688 风格”：大红大黄、满屏信息、弹窗客服、跑马灯公告；导航是“公司简介 / 企业文化 / 荣誉资质 / 新闻动态 / 联系我们”；About 放领导致辞、领导视察、会议合影；证书是高新企业、省级名牌；联系方式是微信二维码和“欢迎来电” | **一律以出海目标市场的风格主导，不在国内站基础上做“翻译版”**。三条规则：① 结构重来——导航按目标市场本土同行的结构（Products / Solutions 或 Industries / OEM / About / Contact），去掉“企业文化 / 新闻动态 / 荣誉资质”这类国内站惯用栏目，荣誉并入 About 的认证区、新闻改为解决采购问题的 Blog；② 视觉重来——色彩饱和度、信息密度、字体按第五步的目标市场修正（欧美克制留白、中东拉美可饱和一档、日韩精致密集），不沿用国内站的红黄配色、跑马灯公告、浮动客服弹窗、满屏铺排；③ 内容只取事实——从国内资料里只抽数字、证书、设备、案例、产品参数，叙事部分（领导致辞、企业文化、情怀式发展历程）不搬，国内证书只在有国际对应或采购能理解时保留并加解释。旧站体检的结论多数落在“重做”或“推倒”，方案里明写“国内站的 X 在目标市场会传递 Y 信号，所以改为 Z”（例如领导视察照片在欧美采购眼里是政府关系而非产能证据 → 换车间实拍；满屏跑马灯在欧美是廉价信号 → 换留白与数字）。你说“国内站挺好的，照那个做”时，agent 用研究员拆的本土同行截图对照说明，不直接照搬。没有明确目标市场时，按英文国际站默认（国际企业风、欧美密度）处理，不按国内审美 |
