# 参考 · 可用性与可访问性检查项

这一份是**测试阶段逐条过的检查表**，不是设计参考。级别就是缺陷定级：P0 阻断上线，P1 上线前必须清，P2 记录并在一个月内修，P3 记录即可。

**用法**：出测试报告时逐条对照，命中的写进报告并给出页面与元素位置。不要整段抄进报告——只写命中的那几条。

**这一份只管「用起来对不对」**。实现层面的检查（表单、性能、响应式、触摸、动效、布局）在 `b2b-frontend-dev/references/前端自查表.md`，两份不重叠。

> 数据改编自 [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)（MIT License, Copyright (c) 2024 Next Level Builder）。已按出海 B2B 询盘站的场景筛选、重写分层并补充结论，条目与原表不一一对应。


### 可访问性

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P0 | 文本重排 | 用流式字号、由内容决定高度、行高不带单位 | 把文字锁在固定宽高的盒子里裁掉 |
| P0 | 小控件语义 | 优先用 button，并让按下或选中状态和可见标签一致 | 用可点的 div，或把唯一的操作藏在悬停里 |
| P1 | 对比度 | 正文至少 4.5:1 | 浅灰字配白底 |
| P1 | 不只靠颜色 | 颜色之外再加图标或文字 | 只用红绿区分成功失败 |
| P1 | 图片替代文本 | 有信息量的图写描述性 alt | alt 为空或干脆没有 |
| P1 | 纯图标按钮的名字 | 给纯图标按钮加 aria-label | 图标按钮没有任何可读名称 |
| P1 | 键盘可操作 | Tab 顺序跟视觉顺序一致，每个操作都能不用鼠标完成 | 焦点陷在弹层里出不来，或 Tab 顺序乱跳 |
| P1 | 表单标签 | 用 label 关联 for，或把 input 包进 label | 只靠 placeholder 当标签，一输入就看不见字段名了 |
| P1 | 错误可被读出 | 错误用 aria-live 或 role=alert | 错误只有视觉提示 |
| P1 | 动效敏感 | `prefers-reduced-motion: reduce` 下全部动效关闭并直接给出最终可读状态（载体场景段停在第一个状态、N 段内容改为常规堆叠）；视差限 1–2 处且不用于正文；平滑滚动库在 reduce 下必须完全停用并交还原生滚动 | reduce 下仍在播；正文做视差；平滑滚动无法关闭 |
| P1 | 焦点不被遮挡（最低） | 用 scroll-padding 避开吸顶元素，常驻浮层要能关掉或让开 | 吸顶导航、页脚、横幅或客服挂件把焦点整个盖住 |
| P1 | 拖拽要有替代 | 同时提供按钮、菜单或点选移动，并保留键盘操作 | 排序、缩放、选择只能靠拖 |
| P1 | 最小点击区 | 至少 24×24 CSS 像素，或用等效间距、行内、用户代理、必要性这几种例外 | 拿原生 44pt / 48dp 当网页的合规标准 |
| P1 | 角标播报 | 用一条完整的状态语句，比如「购物车里 3 件」 | 只播报一个光秃秃的数字，或每个角标都是一个抢播报的实时区域 |
| P2 | 标题层级 | h1–h6 按顺序用 | 跳级，或为了字号大小随便选标题级别 |
| P2 | 语义标签 | 用语义化 HTML 加恰当的 ARIA | 满屏 div，没有任何语义 |
| P2 | 跳到主内容 | 导航多的页面提供跳过链接 | 没有跳过链接 |
| P2 | 焦点不被遮挡（增强） | 焦点元素完全不被自家内容遮挡 | 把这条 AAA 级要求当成 AA 必须项，或让常驻元素遮住焦点的任何一部分 |
| P2 | 焦点圈规格 | 焦点圈至少相当于 2px 周长且状态对比度 3:1 | 把这条 AAA 级要求当成 AA 必须项，或用一圈又细又浅的描边 |
| P2 | 帮助入口一致 | 联系方式、自助帮助、在线客服固定放在同样的位置 | 每个页面帮助入口都在不同地方 |

### 内容呈现

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P0 | 关键文本不截断 | 换行、堆叠、放大容器，或提供一个看得见的完整入口 | 为了卡片一样高，把关键信息夹断 |
| P1 | 小标签语义 | 按标签本身的含义决定用静态还是可交互标记 | 把每个胶囊都做成可点，或只用颜色表示状态 |
| P1 | 小标签溢出 | 只对不可预测的值限宽；用 nowrap 配可收缩的标签；完整文本对键盘、鼠标、触摸都可见 | 让一个小标签折成两行，或只用悬停提示 |
| P2 | 文本截断 | 截断加省略号并提供展开 | 撑破布局或直接溢出 |
| P3 | 日期格式 | 用相对时间或按语言区格式化 | 写 03/04/2026 这种两边都能读的格式 |
| P3 | 数字格式 | 加千分位或用缩写 | 一长串没有分隔的数字 |
| P3 | 占位内容 | 用真实的示例数据 | 满屏 Lorem ipsum |

### 数据录入

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P3 | 批量操作 | 支持多选和批量编辑 | 只能一行一行操作 |

### 反馈与状态

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 加载指示 | 按组件性质选形式，保持布局与焦点稳定，并给出可访问的忙碌状态 | 所有操作套同一个时间阈值，或长时间等待不做解释 |
| P2 | 空状态 | 给一句有用的说明加一个动作 | 白屏 |
| P2 | 错误可恢复 | 给明确的下一步 | 只报错不给出路 |
| P2 | 进度指示 | 多步流程给步骤指示或进度条 | 不知道还有几步 |
| P2 | 轻提示 | 3–5 秒后自动消失 | 提示永远不走 |
| P2 | 确认信息 | 一句简短的成功提示 | 静默成功 |

### 表单可访问性

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 错误汇总可聚焦 | 放在表单顶部，提交失败后把焦点移到它的标题或容器上，每条链接到对应字段，行内错误保留 | 用一个纯视觉的汇总替掉行内错误，或每次失焦就抢焦点 |

### 导航

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 锚点平滑滚动 | 在 html 上设 scroll-behavior: smooth | 点了锚点直接跳，没有过渡 |
| P2 | 吸顶导航占位 | 给 body 加上等于导航高度的上内边距 | 导航盖住第一屏内容 |
| P2 | 当前页高亮 | 用颜色或下划线标出当前所在的导航项 | 看不出自己在哪一页 |
| P2 | 状态可分享 | 切换视图或筛选时同步更新 URL | 动态内容永远是同一个网址，采购没法把筛选结果发给同事 |
| P3 | 面包屑 | 三级以上深度的站才用 | 只有一层的站也放面包屑 |

### 搜索

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P2 | 搜索联想 | 边输入边给建议 | 必须打完再回车 |
| P2 | 无结果 | 写「没有结果」并给建议 | 白屏，或只显示「0 条」 |

### 登录与安全

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P0 | 登录不考记忆力 | 允许密码管理器和粘贴，提供 passkey、OAuth 或其他非记忆型方式 | 禁止粘贴，或只能手抄验证码 |

### 排版可读性

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 正文可读 | 浅底用深字 | 灰底灰字 |
| P2 | 行高 | 正文 1.5–1.75 | 挤成一坨或松得离谱 |
| P2 | 每行字数 | 每行 65–75 个字符 | 大屏上正文横贯到底 |
| P2 | 字号刻度 | 用一套统一的比例 | 字号随手定 |
| P2 | 字体加载 | 用 font-display: swap 或 optional；用后备字体先占好位 | 字体没加载完文字是隐形的，加载完整页跳一下 |
| P2 | 标题可辨 | 标题和正文在字号或字重上要拉开 | 标题跟正文差不多 |
| P2 | 标题断行 | 限定行宽并在不同宽度、字体、语言下测试自然换行 | 承诺具体断在第几行，或到处塞不换行空格和硬写 br |

## 出海 B2B 站要额外注意的四条

这四条在通用表里没有，但在我们的客户身上反复出现：

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P0 | 询盘表单的成功状态 | 提交后跳转到独立的 thank-you 页，页面有下一步指引（预计回复时间、WhatsApp、目录下载） | 只在原地弹一行绿字——采购不确定发出去没有，会重复提交或直接离开 |
| P1 | 中文残留 | 全站英文页面里不出现中文字符，包括 alt、title、表单占位符、图片文件名、404 页 | 主体翻译了但表单占位符还是「请输入您的邮箱」 |
| P1 | 交付区无内部视角 | 根目录 README 与 `交付/` 里的文字读者是客户：无「建站方 / 本案例 / 流水线 / skill / agent / QA / PM」，无 `skills/` `references/` `_内部/` 路径，无「刻意避开了 X」的选型过程，无「已向客户索取」的第三人称 | 把写给自己人的复盘当 README 交出去 |
| P1 | 电话与邮箱可点 | `tel:` 与 `mailto:` 用真实号码，国际号带国家码 | 放 400 号码（海外拨不通）或占位号 `400-000-0000` |
