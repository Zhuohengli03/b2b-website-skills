# 参考 · 前端自查表

前端交付前自己过一遍，命中的自己修，不要留给测试。级别与 QA 一致：P0 阻断，P1 上线前必清，P2 一个月内，P3 记录。

**这一份只管实现层面。** 内容、可访问性语义、导航与反馈的检查在 `b2b-qa-tester/references/可用性与可访问性检查项.md`。

> 数据改编自 [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)（MIT License, Copyright (c) 2024 Next Level Builder）。已按出海 B2B 询盘站的场景筛选、重写分层并补充结论，条目与原表不一一对应。


### 动效

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 动效数量 | 每屏最多让 1–2 个关键元素动 | 所有能动的都动 |
| P1 | 减弱动效 | 检测 prefers-reduced-motion 并降级 | 无视系统的动效偏好设置 |
| P1 | 加载态 | 用骨架屏或转圈 | 界面卡住没有任何提示 |
| P1 | 悬停与点击 | 主要交互用点击触发 | 重要操作只能靠鼠标悬停触发，触摸设备上等于没有 |
| P1 | 轮播可停 | 提供上一张、下一张和暂停；聚焦或悬停时停，减弱动效时也停 | 自动轮播且停不下来 |
| P1 | 动画可中断 | 取消或替换掉上一段动画，直接设最终语义状态并做好清理 | 把状态正确性依赖在 animationend / transitionend 上 |
| P2 | 时长口径 | 用统一的动效时长变量，反馈要跟手 | 把 150–300ms 当成放之四海皆准的硬指标 |
| P2 | 循环动画 | 只用于加载指示 | 装饰元素一直转 |
| P2 | 动画属性 | 只动 transform 和 opacity | 动 width / height / top / left，每帧触发重排 |
| P3 | 缓动曲线 | 进场用减速、离场用加速、匀速进度用 linear | 一律禁用 linear，连匀速旋转和进度条也禁 |

### 表单

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 输入框标签 | 标签始终显示在输入框上方或旁边 | 只用 placeholder 当标签 |
| P1 | 错误位置 | 具体错误写在对应输入框下方，并用 aria-describedby 关联 | 只在顶部给一句「有错误」，不说哪个字段 |
| P1 | 提交反馈 | 先加载态，再成功或失败态 | 点完没反应 |
| P2 | 即时校验 | 大部分字段在失焦时校验 | 全部等到提交才报错 |
| P2 | 输入类型 | 该用 email / tel / number / url 就用 | 所有字段都是 text，手机上弹错键盘 |
| P2 | 自动填充 | 正确使用 autocomplete 属性 | 屏蔽或无视浏览器自动填充 |
| P2 | 必填标识 | 用星号或「必填」字样标出来 | 看不出哪些必填 |
| P2 | 密码可见切换 | 提供显示/隐藏切换 | 只能盲打 |
| P2 | 输入框可辨识 | 输入框要有明确的边框或底色 | 输入框看起来像普通文字 |
| P2 | 不重复填写 | 自动带出之前填过的值，或让用户从已填内容里选 | 同一个地址、同一个账号让人再打一遍 |
| P1 | 字段顺序 | 由易到敏感：姓名、邮箱在前，公司与需求居中，电话最后 | 第一格就要电话或预算 |
| P1 | 电话字段 | 选填，旁边一句说明为什么要 | 必填且不解释，采购留假号或直接走 |
| P1 | 报错后状态 | 保留全部已填内容，焦点落到第一个出错字段 | 报错清空表单，或焦点还停在提交按钮 |
| P1 | 承诺句 | 提交按钮旁一句响应时限 + 一句隐私说明，时限用文案稿里确认过的数 | 什么都不说，或时限自己现编 |
| P1 | 蜜罐 | 隐藏字段非空即丢（实现见 SKILL.md 第 5 步） | 裸表单直接收，或上全屏验证码加摩擦 |
| P1 | 提交按钮文案 | 写动作结果：Request a Quote / Get Pricing，全站同一句 | Submit / Send / 提交 |
| P2 | 字段级流失事件 | 每个字段的 focus 与放弃都打事件，能看出在哪一格流失 | 只打一个「表单提交」事件 |

以上七条的归因与参考形态见 `b2b-site-diagnosis/references/组件与特效.md` 的「询盘表单细则」。

### 交互状态

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 焦点可见 | 每个可交互控件都有可见的焦点圈，弹层里的也要有 | 把 outline 去掉又不给替代样式 |
| P1 | 按钮防重复提交 | 提交时禁用按钮并显示加载态 | 允许连点，询盘进来五条一样的 |
| P1 | 错误提示 | 在出问题的地方旁边给明确提示 | 静默失败 |
| P1 | 危险操作确认 | 删除等不可逆操作前先确认 | 直接删 |
| P2 | 悬停反馈 | 改光标并给一点视觉变化 | 可点的东西悬停没反应 |
| P2 | 按下反馈 | 加按下态的视觉变化 | 点下去毫无反应 |
| P2 | 禁用态 | 降低不透明度并改光标 | 禁用态和正常态长得一样 |
| P2 | 成功提示 | 给成功提示或明显的视觉变化 | 做完了没有任何确认 |

### 布局与层级

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 层级管理 | 定一套层级刻度（10 20 30 50） | 随手写 9999 |
| P1 | 内容跳动 | 异步内容先占好位，或放进高度由内容决定的稳定容器 | 内容加载完把下面的东西全顶下去 |
| P1 | 长串换行 | 用 overflow-wrap: anywhere，并让 flex / grid 的文字子项可收缩 | 对所有正文一律 word-break: break-all |
| P1 | 标签组换行 | 让整组换行，或用一个可操作的 +n 展开隐藏项 | 把所有标签挤成一行裁掉，或直接藏掉溢出的值 |
| P2 | 溢出裁切 | 先确认内容装得下再说 | 哪里出问题就在哪里加 overflow:hidden |
| P2 | 固定定位 | 算上安全区和其他固定元素 | 多个固定元素互相叠 |
| P2 | 层叠上下文 | 搞清楚什么会创建新的层叠上下文 | 以为 z-index 能跨上下文生效 |
| P2 | 视口单位 | 用 dvh，或把手机浏览器工具栏算进去 | 手机全屏布局用 100vh |
| P2 | 正文宽度 | 正文容器限制在 65–75 个字符宽 | 正文横贯整个屏幕 |

### 性能

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 图片优化 | 尺寸和格式都要合适（WebP） | 把手机原图直接扔上去 |
| P2 | 懒加载 | 首屏以下的图片和内容懒加载 | 一次性全加载 |
| P2 | 代码分割 | 按路由或功能拆包 | 一个大包打天下 |
| P2 | 缓存策略 | 设置合适的缓存头 | 完全没有缓存策略 |
| P2 | 字体加载 | 用 font-display: swap 或 optional；用后备字体先占好位 | 字体没加载完文字是隐形的，加载完整页跳一下 |
| P2 | 第三方脚本 | 非关键脚本用 async 或 defer | 同步加载第三方脚本，把首屏拖死 |
| P2 | 包体积 | 盯着包体积别让它涨 | 从来不看 |
| P2 | 阻塞渲染 | 关键 CSS 内联，其余延后 | 一个巨大的阻塞式 CSS |

### 响应式

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 触摸目标 | 手机上把可点区域放大 | 手机上还是那个小按钮 |
| P1 | 移动端字号 | 手机正文至少 16px | 手机上一堆小字 |
| P1 | viewport 声明 | width=device-width, initial-scale=1 | 没写或写错 |
| P1 | 横向滚动 | 确保内容不超出视口宽度 | 整页能左右拖 |
| P2 | 移动优先 | 先写手机样式再加断点 | 桌面优先，手机端一堆问题 |
| P2 | 断点实测 | 在 320 / 375 / 414 / 768 / 1024 / 1440 都看一遍 | 只在自己电脑上看 |
| P2 | 图片自适应 | 图片加 max-width: 100% | 固定宽度图片撑破布局 |
| P2 | 表格处理 | 参数表用横向滚动容器，或手机端改卡片式 | 宽表格把整页撑破 |

### 渲染级自查

上面各节查的是代码，这一节查的是渲染出来的画面（参考 ux-ui-agent-skills / oil-ui）。机器化部分用 `node scripts/check.mjs dist --shots` 跑，人工只补机器查不到的。

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P1 | 三档截图 | 每个模板出 1440 / 390 / `prefers-reduced-motion: reduce` 三档截图拼成一张，存 `_内部/06-站点记录/截图/` | 只在自己屏幕上看一眼，不留图 |
| P1 | 横向溢出 | 每档实测 `document.documentElement.scrollWidth > window.innerWidth` 为假 | 整页能左右拖，或靠 `overflow-x: hidden` 盖住 |
| P1 | 触控目标实测 | 可点元素渲染后 `getBoundingClientRect()` 不小于 24×24（规范写 44，测的底线 24；参考 ux-ui-agent-skills，对应 WCAG 2.2 最低档） | 按设计稿数值当实测，或图标按钮 16px 没有内距 |
| P1 | hover / focus 态对比度 | 悬停与聚焦后的文字与底色实测仍达标 | 只测默认态，悬停变浅后白字糊在浅色上 |
| P1 | 裸 hex | 颜色只引用 CSS 变量，`#` 色值只出现在 `:root` 与深色模式的变量重定义里 | 组件里直接写 `#2a5db0` |
| P1 | emoji 当图标 | 图标一律用策划定的图标库 | 用 ✅ 🚀 📞 当功能图标 |
| P1 | 隔离评审 | G3 前由一个不读源码、不读设计理由的子 agent 按 `b2b-site-diagnosis/references/客户速查与自查.md` 给首页 1–10 分并列出可删文字，结果附在本表末尾 | 自己给自己打分；没做就留空（必须注明「未独立评审」） |

### 密钥与外链

| 级别 | 检查项 | 应该 | 不应该 |
|---|---|---|---|
| P0 | 密钥不进静态产物 | 静态站的 Formspree / Resend / 任何 API key 只放在服务端或表单服务自己的端点配置里；提交前 grep 一遍 HTML、JS、`.map` sourcemap 与仓库历史 | 把 key 写进 HTML、JS、sourcemap，或把 `.env` 提交进仓库 |
| P1 | 外链逐条 HEAD | 每条站外链接（证书查询页、客户站、社媒、地图）逐条 `HEAD` 请求返回 200，结果记进自查表 | 只点开过几条，或 3xx / 4xx 当作「能打开」 |
| P2 | 外链属性 | 站外链接 `rel="noopener"`，新窗口打开的加 `target="_blank"` 并在文字或图标上可辨 | 站外链接在当前窗口把采购带走且不可返回 |
