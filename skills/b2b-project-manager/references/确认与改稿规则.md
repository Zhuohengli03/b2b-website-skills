# 参考 · 确认与改稿规则

## 为什么要有闸

生产只要几小时，所以「先做完再给客户看」在成本上可行——但在生意上是错的。

客户对一个已经做完的站提意见，提的是「我不喜欢这个颜色」，你要么全站重来，要么花一小时说服他；客户对一页纸的方向单提意见，提的是「换成蓝色」，五分钟的事。**闸不是为了省我们的工时，是为了让客户的意见落在还能便宜改的地方。**

第二个理由更重要：**闸就是产品本身。** 卖的不是页面数，是客户能介入几次、每次看到多少、能改几轮。

## 四道闸

| 闸 | 客户看什么 | 只收什么意见 | 回复时限 |
|---|---|---|---|
| **G1 结构** | 站点地图 + 首页逐屏线框 | 页面有没有少、顺序对不对、首屏该放什么 | 2 个工作日 |
| **G2 方向** | 视觉方向单（一页纸，不是页面） | 配色、字体、气质像不像这家公司 | 1 个工作日 |
| **G3 设计** | 首页桌面 + 首页手机 + 一个内页 | 版式、层级、区块排布 | 2 个工作日 |
| **G4 验收** | 测试站全站 | 事实错误与缺陷 | 3 个工作日 |

文案不单独设闸：客户只核事实，把 `事实来源表.md` 的中文事实列发过去核对，英文表达不给客户改。这一步不算轮次，也不阻塞下游。

## G2 视觉方向单是什么

**一页纸，不是页面。** 包含六样（第五样只写文字，不出任何画面）：

1. 主色 / 辅色 / 强调色的色块，每块标 HEX 和取自哪里（**优先从客户 logo 吸色**，不新造品牌色）
2. 标题字体 + 正文字体，各写一行真实示例：公司英文名、一个真实产品型号
3. 四个元件的样子：按钮三态、卡片、参数表表头、询盘入口
4. **参考站**：从 `研究简报.md` 里取 3–5 个目标市场同行，每张标出「我们要的是这个感觉的哪一点」
5. 一句话：为什么这个方向适合这家公司——对上四项输入（客户类型 / 产品性质 / 目标市场审美 / 素材条件）的哪几项

**为什么不直接给首页**：客户看到完整首页时会同时对结构、配色、文案、图片提意见，四类混在一起，改完就是拼凑品——行业里管这叫「A 的页头 + C 的页脚 + B 的字体」。方向单只有配色和字体两个变量，客户的意见必然落在这两件事上。

**这一步过了，只出一版首页，不出三版让客户挑。** 出三版的代价是：客户会从三版里各挑一块，而且三版里通常有两版是我们自己都不推荐的。

## 一轮改稿是什么

**一轮 = 客户一次性提交的一份编号清单。** 不是一条意见一轮，也不是三天里陆续发的十条微信算一轮。

三条规矩：

1. **一次提完**。时限内把意见汇总成一份编号清单发过来。时限内分几次发的合并算一轮；超过时限再补的算下一轮。
2. **多人意见先内部统一**。老板、销售、家属的意见由客户方拍板人合并后再发；互相矛盾的退回让拍板人定，**我们不当裁判**。
3. **改完再看**。一轮改完重新提交，客户在时限内确认或提下一轮。

## 几道闸、几轮

**轮次以报价单为准，不要凭印象给。**

| 闸 | 轮次 |
|---|---|
| G1 结构 | **1 轮** |
| G2 方向 | **1 轮** |
| G3 设计 | **2 轮** |
| G4 验收 | 只修缺陷，**不计轮次** |
| 闸数合计 | **4 道** |
| G3 给几张 | 首页桌面 + 手机 + 一个内页 |
| 超出免费轮次 | **按报价单约定加价**，并顺延交期 |

**G3 那一行就是报价单「修改次数 2 轮」说的那个数**——报价单那一栏指的是页面设计阶段，G1 与 G2 的轮次是另加的。别把它读成「整个项目只能改 2 次」，也别反过来按「每闸 2 轮」给，那样会变成 8 轮。

**G1 和 G2 的轮次几乎不花成本**：改的是草图和一页纸，几分钟的事，而这两轮恰恰是用来避免 G3 返工的。给客户看是加码，对我们是省事。

## 过了闸就冻结

**每道闸只收自己层级的意见，过闸后这一层不再免费改。**

| 客户提出 | 属于哪一闸 | 怎么处理 |
|---|---|---|
| G3 时说「导航少一个页面」 | G1 结构 | 已确认，属结构改动 → 计费或进二期 |
| G3 时说「主色换成蓝的」 | G2 方向 | 同上 |
| G4 时说「这个区块换个排法」 | G3 设计 | 同上 |
| 任何闸说「这个数字写错了」 | 事实错误 | 必改，**不算轮次** |
| 任何闸说「这里我看不懂」 | 沟通问题 | 我们解释，不改，**不算轮次** |

这条不是为了卡客户，是为了让「两轮免费」有意义。**不冻结的话，客户在验收时把配色推翻，前面所有轮次都白算。**

说法：「配色我们在第二步一起定过了，现在改的话设计和前端都要跟着动，这属于结构改动。你确实想换的话我给你报个价，或者放进二期。」

## 不算轮次的三类

1. **事实错误**——数字、证书、参数、公司名写错
2. **我们做错了**——没按已确认的方案做
3. **客户问问题**——不涉及改动

## 客户不回怎么办

沿用超时规则：到期 3 个工作日提醒并附「默认按当前版本推进」；第 5 天视为确认并顺延；第 10 天冻结项目并书面通知。

**视为确认的闸同样冻结**——第 5 天默认通过之后，客户再来推翻这一层按计费处理。这一条必须在开工会上讲过并写进排期，否则不能执行。

## 报价单里必须写的五条

照抄，不要改措辞：

- 本项目包含 **4 道确认节点**，各节点的免费轮次（照上面那张表抄）
- 一轮修改指：**一份编号清单，一次提交**
- **事实错误不计入轮次**
- 已确认节点所属层级如需变更，按需求变更**另行报价**，不占用免费轮次
- 免费轮次用尽后追加修改 **按报价单约定加价**，交付时间相应顺延
- 每道节点需在 **X 个工作日**内回复，逾期按当前版本推进

## 确认记录

每道闸在 `_内部/确认记录.md` 留一行：

| 闸 | 发出时间 | 发了什么 | 客户回复时间 | 回复原文或截图路径 | 本闸第几轮 | 结论 |
|---|---|---|---|---|---|---|

这是收款、防返工、以及日后客户说「我没同意过」时**唯一的依据**。没有这一行，就当没确认过。

## 客户版怎么说

同样的规则给客户看时不用「闸」「轮次冻结」这类词。客户版的完整措辞在你自己的**服务条款**和**报价单**里，PM 直接发链接或截图，不要自己现编一套说法——两边说法不一致是纠纷的开始。

## 常见错误

- **把方向单和首页一起发**——客户的意见会混成一团，等于没设方向闸
- **出三版让客户挑**——挑出来的是拼凑品
- **客户零碎发意见就零碎改**——一轮变成十轮，还容易漏
- **过了闸的层级还免费改**——免费轮次立刻失去意义
- **逾期视为确认没提前讲**——事后拿出来会变成纠纷
- **按「每闸 2 轮」给**——那是 8 轮，报价单卖的是页面设计 2 轮
- **自己现编一套跟客户的说法**——以你的服务条款和报价单为准
- **闸的产出没进确认记录**——收尾款时拿不出依据
