# 参考 · 确认与改稿规则

## 为什么要有闸

生产只要几小时，所以「先做完再给你看」在成本上可行——但在结果上是错的。

你对一个已经做完的站提意见，提的是「我不喜欢这个颜色」，要么全站重来，要么花一小时说服你；你对一页纸的方向单提意见，提的是「换成蓝色」，五分钟的事。**闸不是为了省工时，是为了让你的意见落在还能便宜改的地方。**

## 四道闸

| 闸 | 你看什么 | 这一步只定什么 | 过了触发什么 |
|---|---|---|---|
| **G1 结构** | 站点地图 + 首页逐屏线框 | 页面有没有少、顺序对不对、首屏该放什么 | 文案开写；设计出视觉方向单 |
| **G2 方向** | 视觉方向单（一页纸，不是页面） | 配色、字体、气质像不像这家公司 | 设计出首页 |
| **G3 设计** | 首页桌面 + 首页手机 + 一个内页 | 版式、层级、区块排布 | 前端 + 后端开工 |
| **G4 验收** | 测试站全站 | 事实错误与缺陷 | 上线与交接 |

文案不单独设闸：你只核事实，把 `事实来源表.md` 的中文事实列给你核对，英文表达由文案负责。这一步不算返工，也不阻塞下游。

## G2 视觉方向单是什么

**一页纸，不是页面。** 包含六样（第五样只写文字，不出任何画面）：

1. 主色 / 辅色 / 强调色的色块，每块标 HEX 和取自哪里（**优先从你们的 logo 吸色**，不新造品牌色）
2. 标题字体 + 正文字体，各写一行真实示例：公司英文名、一个真实产品型号
3. 四个元件的样子：按钮三态、卡片、参数表表头、询盘入口
4. **参考站**：从 `研究简报.md` 里取 3–5 个目标市场同行，每张标出「要的是这个感觉的哪一点」
5. 一句话：为什么这个方向适合这家公司——对上四项输入（买家类型 / 产品性质 / 目标市场审美 / 素材条件）的哪几项

**为什么不直接给首页**：看到完整首页时你会同时对结构、配色、文案、图片提意见，四类混在一起，改完就是拼凑品——行业里管这叫「A 的页头 + C 的页脚 + B 的字体」。方向单只有配色和字体两个变量，你的意见必然落在这两件事上。

**这一步过了，只出一版首页，不出三版让你挑。** 出三版的代价是：你会从三版里各挑一块，而且三版里通常有两版是设计自己都不推荐的。

## 什么算返工

**返工 = 过了闸之后，再回头改上一层已经定下的东西。** 本层意见在闸上改，不算返工。

提意见的三条规矩：

1. **一次提完**。把意见汇总成一份编号清单一次给 PM，不零碎发。
2. **多人意见先内部统一**。老板、业务员、家属的意见由拍板人合并后再给；互相矛盾的退回让拍板人定，**PM 不当裁判**。
3. **改完再看**。一份清单改完重新提交，你确认或再提一份。

**G1 和 G2 的意见几乎不花成本**：改的是草图和一页纸，几分钟的事，而这两道闸恰恰是用来避免 G3 返工的。

## 过了闸就冻结

**每道闸只收自己层级的意见，过闸后这一层冻结。** 再回头改就是返工：agent 要提醒代价（下游哪些产出要重做），但要不要返工你决定。

| 你提出 | 属于哪一闸 | 怎么处理 |
|---|---|---|
| G3 时说「导航少一个页面」 | G1 结构 | 已确认，属返工 → PM 报出要重做的下游产出（设计、前端），你定：返工或放进二期 |
| G3 时说「主色换成蓝的」 | G2 方向 | 同上 |
| G4 时说「这个区块换个排法」 | G3 设计 | 同上 |
| 任何闸说「这个数字写错了」 | 事实错误 | 必改，**不算返工** |
| 任何闸说「这里我看不懂」 | 沟通问题 | PM 解释，不改，**不算返工** |

这条不是为了卡你，是为了让闸有意义。**不冻结的话，验收时把配色推翻，前面所有闸都白过。**

PM 在停点的说法：「配色在第二步一起定过了，现在改的话设计和前端都要跟着重做，属于返工。你确实想换就返工，或者放进二期，你定。」

## 不算返工的三类

1. **事实错误**——数字、证书、参数、公司名写错
2. **agent 做错了**——没按已确认的方案做
3. **你问问题**——不涉及改动

## 确认记录

每道闸在 `_内部/确认记录.md` 留一行：

| 闸 | 发出 | 发了什么 | 你的回复 | 结论 |
|---|---|---|---|---|

这是防返工、以及日后说「我没定过这个」时**唯一的依据**。没有这一行，就当没确认过。

## 常见错误

- **把方向单和首页一起发**——意见会混成一团，等于没设方向闸
- **出三版让你挑**——挑出来的是拼凑品
- **零碎发意见就零碎改**——一份清单变成十次改，还容易漏
- **过了闸的层级不提醒代价就改**——冻结立刻失去意义
- **闸的产出没进确认记录**——返工时说不清哪一层是定过的
