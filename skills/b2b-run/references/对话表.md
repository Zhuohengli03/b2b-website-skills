# 起跑前必答 · 问你（对话表）

（从 `b2b-run/SKILL.md`「起跑前必答 · 问你」一节搬出，原文未改。正文只留了八项的名字和三条通道的一句话版。）

**缺东西时的第一反应是问你，不是自己猜。** 两条通道 + 假设清单，先分清是哪一条：

| 通道 | 什么进这里 | 节奏 | 落盘 |
|---|---|---|---|
| **问你（阻断）**（本节） | 一句话能答、猜错要返工整段、答案在你手里 | **当场问，必须带默认值**（「不答就按 X 推进」） | 答案写进 `RUN.md` 开跑参数或假设清单 |
| **待你决定（不阻断）** | 需要你去翻资料、问老板、拍照片，缺了不影响当前这一步 | 任何岗位追加；PM 在每个停点或攒满 5 条时在对话里整理成一次选择题问你 | `_内部/待用户决定.md`，四栏：谁问 / 缺什么 / 为什么需要 / 不定就按什么推进；每条 ≤ 3 行 |
| **假设清单** | 谁都不确定、缺了不影响当前步 | 成对记：假设什么 / 若不成立改成什么 | `RUN.md` 假设清单 |

判定顺序就一句：**先自己查文件，查不到再看这件事缺了卡不卡当前这一步。** 卡、且你一句话能答 → 当场问；不卡、但要你去翻去问去拍 → 进待你决定；谁都不确定 → 记假设。

## 开跑前一次性问完

第 0 步之前先把下面八项都落实。**能自己查的先查**，查不到或查出歧义（比如资料里有两份需求表）才问，**一次编号列出问完，不要一条一条挤**。

| # | 要落实的 | 先自己查哪里 | 查不到就问你 |
|---|---|---|---|
| 1 | 模式 A / B / C | 当前目录有没有 `./_内部/RUN.md` | 有 RUN.md 但你没说续跑 → 问是接着跑还是重开 |
| 2 | 项目根目录对不对 | 当前工作目录 | 目录里已有别的项目的东西 → 停下来问 |
| 3 | 填好的需求表在哪：`_内部/00-资料/需求表.md` | `00-资料/` 有没有需求表 | 空的、或有多份 → 问哪一份是准的 |
| 4 | 旧站网址 | 需求表里有没有 | 是翻新项目但没网址 → 问 |
| 5 | 有没有硬节点 | 需求表里有没有展会 / 买家来访 / 投广告的日期 | **一律问你**（你多半知道）；你也定不下来就记假设 |
| 6 | 素材实物在哪 | `00-资料/` 下的图片、证书扫描 | 你说有但目录里没有 → 问放哪了 |
| 7 | 跑到哪一步停 | — | **一律问**。你不指定就按「每道闸都停」 |
| 8 | **拍板人：你本人 / 另有老板（需要转述）** | 需求表里有没有写 | 查不到就问。另有老板 → 每道闸的东西按「能转述给老板看」的形式摆出来 |

答完写进 `RUN.md` 的「开跑参数」一节，之后本次运行不再重复问。

## 跑到一半要问你

三条同时满足才当场问，否则进待你决定或假设清单：

1. 答案在**你**手里，不需要你去翻资料、问老板、拍照片
2. 猜错要返工**整段**，不是改一行字
3. 一句话能答完

问的时候**必须带上默认值**——「你不答我就按 X 推进」，让你能直接回一句「按你说的」。只抛问题不给默认值，等于把停顿甩给你。你一时定不下来 → 按默认值推进，成对记进假设清单。

## 问你：只有一个出口（契约）

要你翻资料、问老板、拍照片才能定的事，一律追加到 `_内部/待用户决定.md`（谁问 / 缺什么 / 为什么需要 / 不定就按什么推进），**不写进自己的产出，不各自在对话里问**。到停点或攒满 5 条时**调用 `b2b-project-manager` 汇总**，在对话里整理成一次选择题问你，一次最多 5 条，每条带默认值。你的答复回填同一文件，再分发给对应岗位。`RUN.md` 只记「待用户决定 已问 N 条 / 已答 N 条」。九个 agent 各自问你，是你的时间被耗光的最快方式。
